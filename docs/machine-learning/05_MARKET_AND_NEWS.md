# 5. 국내외 시장과 뉴스 결합

가격 특징만으로 만든 첫 모델이 정상적으로 평가된 뒤 추가합니다. 여러 데이터를 처음부터 함께 넣으면 무엇이 성능을 바꿨는지 알기 어렵습니다.

## 시장 데이터 추가 순서

1. 코스피·코스닥 수익률과 변동성
2. 상승·하락 종목 비율과 거래대금
3. 종목 업종의 상대 수익률
4. 원/달러 환율 변화
5. 전날 S&P 500·나스닥·반도체 지수
6. 당일 확인 가능한 해외 지수선물과 아시아 시장
7. 금리·변동성 지표

미국 전일 종가와 국내 장중 선물은 사용할 수 있는 시점이 다르므로 같은 필드로 합치지 않습니다.

## 시장 국면

전체 시장을 상승·하락·횡보·고변동 구간으로 나누고 다음 중 하나로 사용합니다.

- 종목 모델의 입력 특징
- 국면마다 다른 승인 기준
- 급락·고변동 국면의 신규 매수 차단

## 뉴스 데이터

현재 프로젝트가 가진 제목, 출처, 게시 시각과 유사 기사 묶음을 먼저 활용합니다.

- 최근 10분·60분 뉴스 수와 증가 속도
- 서로 다른 언론사 수
- 신규 사건과 반복 기사의 구분
- 종목·업종·시장 관련 범위
- 공시 여부와 종류
- 제목 기반 긍정·부정·불확실성 점수

본문 사용 권한과 저장 정책이 정해지기 전에는 기사 본문을 학습 데이터로 저장하지 않습니다.

## 텍스트 모델 단계

1. 규칙 기반 키워드 점수
2. 기존 한국어 감성 분류 모델 비교
3. 텍스트 임베딩을 사용한 유사 사건 군집
4. 충분한 정답 데이터가 쌓인 뒤 금융 뉴스 영향 모델

뉴스 모델은 직접 매수를 명령하기보다 위험 점수나 승인 기준 조정에 우선 사용합니다.

## 추가 효과 검증

같은 기간과 체결 규칙에서 다음 실험을 비교합니다.

```text
가격 특징만
가격 + 국내 시장
가격 + 국내외 시장
가격 + 국내외 시장 + 뉴스
```

특징을 추가했는데 최종 시험 성과가 좋아지지 않으면 복잡도만 늘어난 것이므로 제외합니다.
