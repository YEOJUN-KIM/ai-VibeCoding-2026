# 6. PAPER 실시간 운용

문서 상태 (2026-10-04): 후속 설계입니다. 현재 모의매매는 이동평균 전략이며 실시간 매매용 모델 추론은 연결하지 않았습니다. 실제 진행은 [구현 현황](CURRENT_PROGRESS.md)을 따릅니다.

휴대폰 상태 확인·원격 정지 계획과는 별개의 모델 운용 설계입니다.

## 실시간 흐름

```text
완료된 1분봉 수신
→ 시점 기준 특징 생성
→ 기존 전략의 매수 후보 생성
→ 승인 모델 예측
→ 기준 통과 시 PAPER 주문
→ 예측·판단 이유·체결·결과 저장
```

## 모델 구성 파일

승인된 모델은 다음 정보와 함께 보관합니다.

- 모델 ID와 버전
- 생성 시각과 코드 식별자
- 학습·검증·시험 기간
- 특징 목록과 순서
- 전처리기와 모델 파일의 해시
- 수수료·세금·슬리피지 가정
- 승인 확률 기준
- 기준 전략과 비교 결과

## 사용자 안내와 내부 점검

사용자 화면에는 실행 상태·매수 승인 또는 거절 이유·데이터 대기·모의 성과를 우선 표시합니다. 특징 생성 상세, 모델 파일 해시와 점검 이력은 내부 기록에 둡니다. 아래 후보를 모두 화면에 추가하는 요구사항은 아니며 모델 도입 시 필요한 범위를 결정합니다.

- 사용 중인 모델 버전
- 마지막 정상 특징 생성 시각
- 예측 확률과 예상 순수익
- 매수 승인 또는 거절 이유
- 누락되거나 지연된 데이터
- 기존 전략 대비 PAPER 누적 성과

## 장애 처리

- 모델을 읽지 못하면 자동 승인하지 않는다.
- 특징이 누락되거나 순서가 다르면 예측하지 않는다.
- 시세·시장·뉴스가 오래됐으면 주문하지 않는다.
- 예측 시간 제한을 넘으면 주문하지 않는다.
- 모델 오류가 손절·익절 등 기존 청산을 막지 않게 분리한다.
- 이전 승인 모델로 되돌릴 수 있게 보존한다.

## 운용 주기

매일 데이터 누락과 예측 결과를 확인하고, 주 단위로 모델과 기준 전략의 성과를 비교합니다. 새 모델은 기존 모델과 동시에 PAPER 예측만 수행하는 그림자 모드를 거친 뒤 교체합니다.

자동 재학습은 초기 목표가 아닙니다. 먼저 사람이 결과 보고서를 확인하고 승인한 모델만 PAPER 활성 모델로 바꿉니다.

## LIVE 전환 기준

LIVE 자동주문은 현재 머신러닝 과정의 완료 조건이 아닙니다. 충분히 긴 PAPER 기간, 다양한 시장 국면, 비용 차감 후 안정성, 장애·재시작 복구와 별도 승인 절차가 모두 검증된 뒤 별도 프로젝트 단계로 판단합니다.
