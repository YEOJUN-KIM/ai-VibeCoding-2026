# 머신러닝 자동매매 학습 과정

이 폴더는 자동매매 수익 개선과 포트폴리오 학습을 함께 진행하기 위한 전용 문서입니다. 현재 전략 기준은 [모의 전략 설명](../specs/PAPER_STRATEGY.md), 구현 일정은 [로드맵](../ROADMAP.md)을 기준으로 하며, 이 폴더는 머신러닝을 어떤 순서로 배우고 구현할지 설명합니다.

사이트의 기본 기능 구현은 대부분 마쳤습니다. 당장은 새 기능을 늘리지 않고 데이터 축적·품질 검사·모의 운용 확인을 진행합니다. 이후 모델 학습과 모의 판단 연결을 검증하며 실제 자동매매 연결은 별도 단계로 결정합니다. 자세한 우선순위는 [상위 로드맵](../ROADMAP.md)을 참고합니다.

## 프로젝트 목표

첫 목표는 주가를 정확히 맞히는 모델이 아닙니다.

> 기존 전략에서 매수 후보가 발생했을 때, 향후 일정 시간의 비용 차감 후 기대수익을 예측해 매수를 승인하거나 거절한다.

모델의 성공 여부는 정확도만으로 판단하지 않습니다. 기존 이동평균 전략과 비교해 다음 항목이 개선되어야 합니다.

- 수수료·세금·슬리피지 차감 후 순손익
- 거래당 평균 순손익과 손익비
- 최대 낙폭
- 충분한 거래 표본에서의 안정성
- 학습에 사용하지 않은 미래 기간의 성과

## 진행 순서

현재 진행 상태: **1단계 완료, 2단계 구현 완료·데이터 누적, 3단계 첫 백테스트 CLI 구현·다일 검증 대기 (2026-10-04 문서 확인)**. 종목·국내 지수 1분봉, 환율·미국 시장 지표, PAPER 판단과 일일 품질 보고서를 PostgreSQL에 저장하고 비용 포함 기준선 백테스트를 실행할 수 있습니다. 첫 실제 실행 결과와 검증 범위는 [CURRENT_PROGRESS.md](CURRENT_PROGRESS.md)에 정리했습니다. 4단계 모델 학습·6단계 실시간 모델 추론은 구현 완료가 아닙니다.

| 단계 | 목표 결과·현재 범위 | 배우는 내용 | 문서 |
|---|---|---|---|
| 1 | 재현 가능한 ML 개발 환경 | 가상환경, 패키지와 의존성 | [01_ENVIRONMENT.md](01_ENVIRONMENT.md) |
| 2 | 원본 시계열 데이터 저장 | API 수집, DB 설계, 품질 검사 | [02_DATA_PIPELINE.md](02_DATA_PIPELINE.md) |
| 3 | 비용 포함 백테스트: CLI 구현, 여러 거래일 검증 대기 | 벤치마크, 미래 누출과 성과 지표 | [03_BACKTEST.md](03_BACKTEST.md) |
| 4 | 첫 진입 필터 모델: 후속 설계 | 특징, 정답, 분류와 시간순 검증 | [04_FIRST_MODEL.md](04_FIRST_MODEL.md) |
| 5 | 시장·해외·뉴스 결합: 원본 일부 수집, 모델 결합은 후속 | 시장 국면, NLP와 다중 데이터 | [05_MARKET_AND_NEWS.md](05_MARKET_AND_NEWS.md) |
| 6 | PAPER 실시간 추론: 후속 설계 | 모델 버전, 장애 대응과 모니터링 | [06_PAPER_OPERATIONS.md](06_PAPER_OPERATIONS.md) |
| 7 | 포트폴리오 정리 | 문제·실험·결과를 설명하는 방법 | [프로젝트 소개·근거 정리](../PROJECT_OVERVIEW.md) |

## 단계별 통과 조건

다음 단계로 넘어가기 전에 현재 단계의 결과를 재현할 수 있어야 합니다.

1. 같은 명령을 실행하면 같은 환경이 만들어진다.
2. 특정 시각에 실제로 알 수 있었던 데이터만 저장된다.
3. 같은 데이터와 설정으로 같은 백테스트 결과가 나온다.
4. 시간순 검증에서 기준 전략보다 나은지 수치로 비교된다.
5. 시장·뉴스 데이터를 추가했을 때 기여도가 따로 측정된다.
6. PAPER에서 모델 장애가 주문 장애로 번지지 않는다.
7. 제3자가 README만 보고 문제, 설계, 한계와 결과를 이해한다.

## 하지 않을 것

- 처음부터 딥러닝이나 강화학습을 적용하지 않습니다.
- 무작위 데이터 분할로 시계열 모델을 평가하지 않습니다.
- 테스트 기간의 결과를 보고 같은 기간의 설정을 반복 수정하지 않습니다.
- 정확도 하나만으로 실제 사용 여부를 결정하지 않습니다.
- 모델이 좋다는 이유만으로 LIVE 자동주문을 바로 활성화하지 않습니다.

딥러닝은 장기간 데이터, 신뢰할 수 있는 백테스트, 단순 모델과 PAPER 운영 결과가 준비된 뒤 별도 비교 실험으로 진행합니다.
