## 보여줄 이야기

포트폴리오는 모델 정확도보다 문제를 어떻게 정의하고 검증했는지 보여줘야 합니다.

1. 단순 이동평균 전략이 횡보장에서 거래비용을 누적시키는 문제를 발견했다.
2. 실제 시세·뉴스·시장 데이터를 시간 기준으로 수집하는 파이프라인을 만들었다.
3. 비용과 미래 누출을 반영한 재현 가능한 백테스트를 구축했다.
4. 단순 모델부터 시작해 시간순으로 비교했다.
5. 국내외 시장과 뉴스 특징의 추가 효과를 분리 실험했다.
6. 모델을 PAPER 실시간 시스템에 연결하고 실패 시 안전하게 중단하도록 설계했다.
7. 한계와 실패한 실험도 기록했다.

## 결과물

- 시스템 구성도와 데이터 흐름도
- 데이터 사전과 테이블 관계
- 특징·정답 정의서
- 백테스트 실행 방법
- 기준 전략과 모델별 비교표
- 자산 곡선과 낙폭 그래프
- 시간순 검증 구간 그림
- 모델 카드와 버전 메타데이터
- PAPER 운영 화면과 장애 대응 사례
- 재현 가능한 설치·학습 명령
