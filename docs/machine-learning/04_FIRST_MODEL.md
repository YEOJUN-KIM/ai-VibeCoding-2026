# 4. 첫 머신러닝 모델

2026-10-03 기준 후속 설계입니다. 개발 환경 확인용 작은 예제 모델과 별개로, 실제 수집 데이터로 검증한 진입 필터 모델은 아직 없습니다. 데이터·백테스트 준비 후 진행합니다.

## 첫 문제 정의

이동평균 매수 후보가 생긴 시점마다 다음 질문에 답합니다.

> 향후 20분 안에 청산했을 때 비용 차감 후 목표 수익을 낼 확률은 얼마인가?

첫 모델은 `매수 승인/거절` 이진 분류로 시작합니다. 이후 예상 순수익률을 예측하는 회귀 모델을 비교합니다.

## 첫 특징

- 최근 1·3·5·10·20분 수익률
- 단기·장기 이동평균 간격과 기울기
- 최근 거래량 비율
- 최근 고가·저가 범위와 변동성
- 시가 대비 현재 위치
- 장 시작 후 경과 시간
- 국내 지수와 업종 수익률

정답에는 매수·매도 비용을 모두 반영합니다. 여러 예측 시간이 겹칠 수 있으므로 학습과 검증 사이에 충분한 `gap`을 둡니다.

## 모델 비교 순서

1. 항상 거절 또는 기존 전략 그대로 실행하는 기준선
2. 로지스틱 회귀
3. 랜덤 포레스트
4. HistGradientBoosting
5. LightGBM

복잡한 모델은 단순 모델보다 미래 기간의 순손익이나 위험 조정 성과가 좋아야 채택합니다.

## 시간순 검증

무작위 `train_test_split`을 사용하지 않습니다.

```text
1~3월 학습 → 4월 검증
1~4월 학습 → 5월 검증
1~5월 학습 → 6월 최종 시험
```

종목이 여러 개여도 같은 시점의 데이터가 학습과 검증에 동시에 섞이지 않게 날짜 단위로 분리합니다.

## 평가

분류 지표인 precision, recall, ROC-AUC와 함께 반드시 거래 성과를 봅니다.

- 승인한 거래의 비용 차감 후 평균 수익
- 기준 전략 대비 제거한 손실과 놓친 이익
- 모델 적용 전후 거래 횟수와 최대 낙폭
- 확률 구간별 실제 수익률
- 월별·종목별·시장 국면별 편차

## 설명 가능성

모델이 사용한 특징, 중요도와 개별 판단 이유를 저장합니다. 특징 중요도는 인과관계를 증명하지 않으며, 데이터 누출이나 특정 기간 의존 여부를 별도로 확인합니다.

## 완료 조건

- 학습 명령 하나로 데이터 생성부터 모델 저장까지 재현된다.
- 미래 기간에서 기준 전략과 비교한 보고서가 생성된다.
- 모델 파일에 특징 순서와 전처리기가 함께 저장된다.
- 예측에 필요한 특징이 누락되면 주문하지 않고 이유를 기록한다.
