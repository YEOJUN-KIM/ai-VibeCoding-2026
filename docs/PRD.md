# 제품 요구사항

## 1. 목적

개인 투자자가 국내주식을 탐색하고 장기 관찰 후보를 좁히며, 자동매매 전략을 PAPER에서 검증한 뒤 명시적인 안전 절차 아래 LIVE 주문으로 이어갈 수 있는 로컬 웹 도구를 만든다.

이 제품은 투자 판단을 보조한다. 수익을 보장하거나 분석 점수를 매수 추천으로 표현하지 않는다.

## 2. 제품 원칙

- PAPER와 LIVE의 화면, 전략 환경, 주문 경로와 기록을 명확히 분리한다.
- 외부 API 실패를 가짜 최신 데이터로 숨기지 않고 지연·오류 상태를 사용자에게 보여준다.
- 실제 주문보다 안전과 추적 가능성을 우선한다.
- 계산 기준일, 데이터 출처와 오래된 데이터 여부를 화면에서 이해할 수 있게 한다.
- 같은 외부 데이터를 여러 화면이 중복 요청하지 않도록 캐시와 사전 로딩을 사용한다.

## 3. 핵심 사용자 흐름

1. 사용자는 PIN으로 로그인하고 DB와 토스 API 준비 상태를 확인한다.
2. 국내주식과 뉴스에서 종목을 찾고 상세 화면에서 가격·기업·장기 분석을 확인한다.
3. 관심종목 또는 내 장기 관찰 후보에 종목을 저장한다.
4. 전략 설정에서 DRY RUN 전략과 위험 조건을 만든다.
5. PAPER에서 전략을 실행하고 판단·주문·포트폴리오·전략 손익을 검토한다.
6. 충분히 검증한 경우에만 LIVE 화면 또는 종목 상세에서 실제 주문 절차를 진행한다.

## 4. 기능 요구사항

### 4.1 인증과 화면 잠금

- 관리자 PIN은 평문으로 저장하지 않는다.
- 로그인 세션은 활동 기반으로 연장되고 서버 재시작 후에도 유효성을 확인할 수 있어야 한다.
- 사용자가 즉시 화면을 잠글 수 있어야 하며 잠금 해제는 기존 실행 상태를 바꾸지 않아야 한다.
- PIN 입력은 브라우저 비밀번호 저장 제안을 불필요하게 유발하지 않도록 구성한다.

### 4.2 시장 탐색

- 국내 종목 검색, 현재가, 차트, 기업정보, 시장정보와 뉴스를 제공한다.
- 뉴스는 유사 사건을 묶고 다양한 주제가 보이도록 한다.
- 관심종목은 서버에 저장하고 다른 화면에서도 같은 상태를 사용한다.

### 4.3 장기 관찰

- 확인 가능한 재무·가격 지표를 점수화하고 점수, 등급, 기준일과 근거를 함께 표시한다.
- 자동 추천 후보와 사용자가 직접 관리하는 후보를 별도 탭으로 제공한다.
- 자동 추천에서는 이미 사용자가 관찰 중인 종목을 제외한다.
- 분석 결과를 저장해 재사용하고 예약된 시간에 갱신한다.
- 공시 이후 분석 결과가 달라질 수 있음을 명시한다.

### 4.4 전략과 PAPER

- 전략 설정 화면은 전략을 작성·보관하고 실행은 PAPER/LIVE 화면에서 담당한다.
- PAPER에는 DRY RUN 전략만 연결할 수 있어야 한다.
- PAPER는 실제 계좌와 분리된 모의 계좌에서 여러 종목을 감시하고 판단과 주문 기록을 구분해 보여준다.
- 수수료·세금·슬리피지와 전략 관리 수량을 반영한 손익을 제공한다.
- 상세 신호·체결·손익 기준은 [PAPER 전략 설명](PAPER_STRATEGY.md)을 단일 기준으로 사용한다.

### 4.5 LIVE 주문

- 실제 주문은 사용자의 명시적인 조작 없이 발생하면 안 된다.
- 주문 PIN, 서버 안전 잠금, 수량·가격·시장 검증, 위험 한도, 중복 요청 방지를 적용한다.
- 요청, 브로커 응답, 상태 변경과 대조 결과를 영구 기록한다.
- 재시작 후에도 미확정 주문을 복구하고 브로커 상태와 대조할 수 있어야 한다.

### 4.6 운영 상태

- DB와 토스 API가 준비되지 않으면 로그인 이후 데이터 요청을 성급히 시작하지 않는다.
- API 한도 대기, 예약 분석, 점검과 장애 상태를 공통 헤더에서 알린다.
- 민감한 값은 `.env`에 두고 로그와 문서에 노출하지 않는다.

## 5. 비기능 요구사항

- 기본 배포 환경은 Windows, PostgreSQL 5432, 단일 Uvicorn 프로세스다.
- 모바일과 데스크톱에서 핵심 표와 버튼이 잘리지 않아야 한다.
- 외부 주문과 저장 동작은 멱등성을 갖고 실패 원인을 추적할 수 있어야 한다.
- 중요한 계산과 안전 조건은 자동 테스트로 검증한다.

## 6. 현재 범위 밖

해외주식, 다중 사용자, AI 뉴스 요약, PAPER 전체 영속화, 전략 자동 학습, 실제계좌 완전 자동매매와 운영 백업 자동화는 현재 요구사항이 아니다. 검토 항목은 [BACKLOG.md](BACKLOG.md)에 둔다.
