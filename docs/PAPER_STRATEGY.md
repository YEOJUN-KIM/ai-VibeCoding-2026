# PAPER 전략 동작과 성과 해석

이 문서는 현재 PAPER 엔진의 계산 기준입니다. 향후 아이디어는 [BACKLOG.md](BACKLOG.md)에 둡니다.

## 데이터와 실행 주기

- 신호 판단은 토스증권의 현재가와 완료된 1분봉을 사용합니다.
- 실행 주기는 설정할 수 있으며 현재 개발 환경의 기본 반복은 10초입니다.
- 여러 화면과 전략이 같은 데이터를 요구하면 캐시된 결과를 공유합니다.
- 시세 요청이 실패하거나 지연됐을 때 임의의 가상 가격으로 주문을 만들지 않습니다.

## 진입 신호

- 저장된 DRY RUN 전략의 단기·장기 이동평균을 계산합니다.
- 단기선이 장기선을 상향 돌파한 뒤 완료된 두 캔들에서 조건이 유지돼야 진입합니다.
- 오래된 캔들, 거래량이 없는 캔들, 재주문 대기 중인 종목은 제외합니다.
- 주문 수량과 위험 한도를 통과한 경우에만 PAPER 매수를 체결합니다.

## 청산 신호

다음 조건 중 하나가 충족되면 전략이 관리하는 수량을 전량 모의 매도합니다.

- 전략의 손절률 도달
- 전략의 익절률 도달
- 최대 보유 기간 도달
- 완료 봉의 단기 이동평균이 장기 이동평균을 위에서 아래로 교차

## 보유 종목 관리 범위

모의매매 페이지에서 계좌별로 선택하며 실행 중 변경은 막습니다. 신규 매수 대상은 어느 범위에서든 현재 전략의 대상 종목으로 한정합니다.

| 범위 | 관리 대상 |
|---|---|
| 현재 전략 종목만 (`CURRENT`) | 현재 전략 대상 종목의 보유분 |
| 자동매매 종목만 (`AUTO`, 기본값) | 자동매매로 매수한 수량만. 현재 전략 밖 자동매수분도 청산 감시 |
| 전체 보유 종목 (`ALL`) | 자동매수분과 수동·미지정 보유분 전체 |

자동매수분은 전략 ID·이름·매수 수량·비용 포함 단가·취득 시각·매수 당시 청산 조건을 함께 저장합니다. 같은 종목을 서로 다른 전략이 매수해도 매수분별로 원래 조건을 적용해 청산하며, 전략 설정을 나중에 수정했다고 기존 자동매수분의 조건이 덮어써지지 않습니다.

수동·미지정 보유분은 CURRENT/ALL에 포함될 때 현재 전략 조건으로 인수합니다. AUTO에서는 제외하며, 출처를 알 수 없는 기존 보유분을 임의의 자동매수 전략으로 연결하지 않습니다. 수동 보유분 인수 시 평가액을 전략 기준선으로 잡으며 자동매수분의 기존 취득 단가와 조건은 유지합니다.

보유 표에서 담당 전략과 현재 전략 운용·청산만 감시·관리 제외를 표시합니다. 상세를 펼치면 매수분별 수량·손절·익절·최대 보유일·운영 시간을 확인합니다. 정지 중에는 자동 청산도 실행되지 않습니다.

## 계좌 전환과 실행

- 화면에서 다른 모의계좌로 전환해도 이전 계좌 워커는 계속 실행됩니다.
- 보고 있는 계좌의 전략 선택·시작·일시정지·긴급 중지는 그 계좌에 적용됩니다.
- 다른 계좌에서 실행 중인 전략은 별도 배너에 계좌·전략 이름·판단 횟수로 표시합니다.
- 서버 종료는 두 워커를 모두 정지합니다. 재시작 후 자산과 자동매수 소유 정보는 복구하지만 자동 실행하지 않습니다.
- 두 계좌는 같은 서버 시세 캐시를 사용하고 잔액·주문·관리 범위·성과는 별개로 유지합니다.

## 체결 비용

- 매수 체결가는 현재가보다, 매도 체결가는 현재가보다 불리하게 슬리피지를 적용합니다.
- 기본 슬리피지는 편도 0.05%이며 `PAPER_SLIPPAGE_RATE`로 설정합니다. 실제 호가 측정값은 아닙니다.
- 매수·매도 수수료와 매도 세금을 손익에 포함합니다.
- 종목 유형별 세금 차이는 아직 세분화하지 않았습니다.

## 수익률 구분

- 계좌 수익: 복사된 기존 자산을 포함한 PAPER 계좌 전체의 평가 변화
- 전략 수익: 전략이 새로 관리한 수량의 실현·평가손익과 비용
- 전략 투입자본: 누적 순투입액의 최대값을 분모로 사용해 매도 뒤 분모가 비정상적으로 작아지는 문제를 막습니다.
- 복사된 보유종목은 복사 시점 가격을 PAPER 기준단가로 사용해 과거 실계좌 손익을 전략 성과에 섞지 않습니다.

따라서 계좌 전체 수익이 음수여도 전략 수익은 양수일 수 있고 그 반대도 가능합니다.

## 기록과 초기화

- 화면에서는 판단 기록과 주문 기록을 분리해 표시합니다.
- 주문 감사 기록은 `.paper-history/orders.jsonl`에 추가되며 다운로드할 수 있습니다.
- 잔액·포지션·주문·자동매수 소유 정보와 관리 범위는 DB에서 복구합니다. 실행 상태·선택 전략·판단 기록·전략 성과 기준선은 메모리에 있으며 재시작 후 다시 선택해 실행합니다.
- 결과 초기화는 마지막으로 복사한 기준 자산 상태로 돌아갑니다.

## 개발용 예외

`PAPER_IGNORE_MIN_CASH_RATIO`와 `PAPER_IGNORE_DAILY_ORDER_LIMIT`는 빠른 개발 검증용입니다. 릴리스 전 두 값을 `false`로 되돌려 모든 PAPER 위험 한도를 적용해야 합니다.

PAPER 성과는 실제 체결 가능성이나 미래 수익을 보장하지 않습니다.
