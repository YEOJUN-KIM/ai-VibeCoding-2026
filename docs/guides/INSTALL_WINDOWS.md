# Windows 설치·실행 안내

기준일: 2026-10-04. 개인용 로컬 웹앱의 설치·운용 안내입니다. 설치형 프로그램·휴대폰 앱·외부 접속은 아직 제공하지 않습니다.

## 1. 평소 실행과 종료

프로젝트 폴더의 **FOLIO.cmd**를 더블클릭합니다. 같은 폴더의 서버가 실행 중이면 기존 화면을 열고 새 서버를 만들지 않습니다.

- 처음에는 `.venv`·기본 패키지를 준비합니다. 기존 설정·DB·키 파일은 유지합니다.
- DB 연결을 확인하고 꺼진 로컬 PostgreSQL 서비스를 시작합니다. 서비스 시작에 필요하면 Windows 권한 확인 창이 뜹니다.
- 테이블을 준비하고 계정이 없을 때만 최초 아이디·비밀번호를 묻습니다. 서버가 준비되면 브라우저를 엽니다.
- 실행 창을 유지합니다. 서버 종료는 **Ctrl+C**이며 브라우저 탭만 닫으면 서버는 계속 실행됩니다. 공유 DB 서비스는 끄지 않습니다.
- 종료할 때 `일괄 작업을 끝내시겠습니까? (Y/N)`가 나오는 경우 배치 실행을 마칠지 묻는 것입니다. 서버는 앞의 Ctrl+C로 이미 종료되므로 이 답으로 전략이 다시 실행되지는 않습니다.
- 재실행하면 모의 자산·주문·선택 전략은 복원되지만 자동매매는 정지 상태입니다. 화면에서 전략을 확인하고 시작합니다.

기본 주소는 `http://127.0.0.1:8000`입니다. 다른 프로그램이 포트를 사용하면 임의로 종료하지 않고 안내합니다. 오류 로그는 `.runtime-logs/server.log`에 남습니다.

## 2. 새 PC에 필요한 것

- Python 3.12 이상. 현재 서브 PC는 3.12.14이며 기존 3.14 환경도 사용합니다.
- PostgreSQL 18의 서버·관리 도구·명령행 도구. Stack Builder는 필요하지 않습니다.
- 프로젝트 소스. Git으로 받거나 소스 폴더를 준비합니다.

Python 설치 시 경로 등록을 선택하고 새 터미널에서 `python --version`을 확인합니다. 일반 실행은 기본 패키지만 설치하며 학습 패키지는 [머신러닝 환경 안내](../machine-learning/01_ENVIRONMENT.md)를 따라 별도로 설치합니다.

## 3. 최초 DB 만들기

PostgreSQL 설치 때 지정한 관리자 암호로 pgAdmin에 접속합니다.

1. 로그인 역할 `paper_local`을 만들고 프로젝트용 암호와 로그인 권한을 지정합니다.
2. DB `auto_trader`를 만들고 소유자를 `paper_local`로 지정합니다.
3. 호스트 `127.0.0.1`, 기본 포트 `5432`, DB·사용자·암호를 확인합니다.

앱이 최초 실행 시 [스키마](../../auto_trader/schema.sql)에 따라 테이블을 준비합니다. 역할·DB 생성 자체는 현재 실행 파일이 대신하지 않습니다.

## 4. 환경 설정과 첫 실행

`.env`가 없으면 실행 도구가 예시를 복사하고 설정을 안내합니다. 직접 준비할 때도 기존 파일을 덮어쓰지 않습니다. 최소 DB 설정은 다음과 같습니다.

```dotenv
POSTGRES_HOST=127.0.0.1
POSTGRES_PORT=5432
POSTGRES_DB=auto_trader
POSTGRES_USER=paper_local
POSTGRES_PASSWORD=직접_지정한_DB_암호
```

설정한 뒤 **FOLIO.cmd**를 다시 실행해 최초 계정을 만들고 로그인합니다. 새 비밀번호는 8~20자이며 화면 잠금·실제 주문 인증에 사용하는 숫자 6자리 PIN은 설정 → 계정·연결에서 등록합니다. 비밀번호·PIN 원문은 DB에 저장하지 않습니다.

DB가 준비되면 증권 API 키 없이도 로그인할 수 있습니다. 연결하지 않은 경우 설정 → 계정·연결에서 키를 등록합니다.

## 5. 증권 연결 등록

토스증권 Open API 관리 화면에서 키를 발급하고 현재 PC의 공인 IP를 허용 IP로 등록합니다. 사이트 설정의 등록·변경 팝업에 **Client ID와 Client Secret을 함께** 입력합니다. API 키 입력란은 Client ID입니다. 허용 IP는 사이트 `.env`가 아닌 증권사 화면에서 관리합니다.

- 새로 등록한 키는 `.local-secrets/`의 Windows 암호화 파일에 저장하며 DB·Git에 넣지 않습니다.
- 기존 관리자 환경 연결은 `.env`의 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET`을 유지할 수 있습니다. 팝업 등록은 `.env`를 수정하지 않습니다.
- `TOSS_ACCOUNT`는 API 계좌가 하나이면 비워 둘 수 있으며 여러 개 반환되면 사용할 `accountSeq`를 지정합니다. 사이트의 여러 실제 계좌 전환 기능을 뜻하지 않습니다.
- 선택적인 `DART_API_KEY`는 기업·재무·배당·공시 조회용입니다.
- 새 Windows 사용자·PC로 옮기거나 키 파일을 잃으면 같은 실제 계좌의 키를 재등록합니다. 파일 복사만으로 복호화할 수 있다고 가정하지 않습니다.

같은 키로 여러 프로그램이 토큰을 계속 발급하면 기존 토큰이 무효화될 수 있으므로 실행 주체를 하나로 유지합니다. 공인 IP 변경 시 허용 IP도 갱신합니다.

## 6. 연결·모의 운용 확인

자산 현황(`/live`)에 보유·현금이 표시되면 조회 연결을 확인할 수 있습니다. 연결 성공만으로 실제 주문이 허용되지는 않습니다. 실제 수동 주문은 PIN·서버 안전 잠금·입력 검증·투자 한도를 거칩니다.

모의매매(`/paper`)는 계좌 카드 선택 → 전략 선택 → 전략 시작 순서입니다. 선택만으로 실행하지 않습니다. 세부 동작은 [모의 전략 안내](../specs/PAPER_STRATEGY.md)를 따릅니다.

컴퓨터·서버가 꺼지거나 절전 상태이면 수집·전략 실행을 계속한다고 가정할 수 없습니다. 현재는 단일 서버 프로세스·로컬 접속을 유지하며 휴대폰 접속을 위해 포트를 개방하지 않습니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| Python을 찾지 못함 | 설치 경로 등록 후 새 터미널에서 버전 확인. 3.12 미만이면 업그레이드 |
| DB 연결·암호 오류 | 서비스 실행, DB 역할·소유권, `.env` 접속 값. 여러 버전이면 `POSTGRES_SERVICE`에 서비스 이름 지정 |
| 키·허용 IP 오류 | Client ID·Secret을 함께 입력했는지, 현재 공인 IP가 등록됐는지 확인 |
| 토큰 오류 | 다른 서버·프로그램이 같은 키를 사용하는지 확인. 앱은 무효 토큰에 한 번 재발급 시도 |
| 요청 한도 오류 | 반복 조회·여러 탭을 줄이고 대기. 캐시가 모든 외부 한도를 없애지는 않음 |
| 포트 사용 중 | 같은 소스 폴더의 서버인지 확인. 다른 프로그램·다른 폴더 서버를 임의 종료하지 않음 |
| 키 파일 복사 후 미연결 | 계정 설정에서 재등록. DB만 이전해도 키는 따라오지 않음 |

백업·새 PC 복원은 [저장·백업 정책](../technical/DATABASE.md)을 따릅니다. 기존 DB는 새 환경 확인이 끝날 때까지 유지합니다.

## 8. 개발용 수동 명령

아래는 프로젝트 루트에서 사용합니다. 평소 실행에는 필요하지 않습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m auto_trader
```

계정 수동 생성은 `.\.venv\Scripts\python.exe -m auto_trader.create_admin`, PIN 수동 설정은 `.\.venv\Scripts\python.exe -m auto_trader.set_live_pin`입니다. API 문서는 `/docs`에 있습니다. 브라우저를 열지 않는 실행은 `scripts/start.ps1 -NoBrowser` 옵션을 사용합니다. 실행 도구의 정책 설정은 해당 실행에만 적용됩니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

자동 테스트 통과와 실제 주문·장중 운용·다른 PC 설치 검증은 구분합니다.
