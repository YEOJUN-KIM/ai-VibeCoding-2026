# 화면·검색 설계

기준일: 2026-10-04. 현재 화면의 공통 원칙, 검색 규칙과 디자인 시안의 범위를 설명합니다. 날짜별 배치 수정 과정은 [과거 변경 기록](../records/CHANGELOG_HISTORY.md)에 둡니다.

## 공통 배치와 표현

- 차콜 배경·바이올렛 브랜드 강조를 사용합니다. 상승·하락은 빨강·파랑, 연결·주문 상태는 기능에 맞는 별도 색으로 구분합니다.
- 주요 페이지는 왼쪽 메뉴, 페이지 내부 구역은 상단 탭을 사용하며 제목·콘텐츠의 공통 좌우 기준선을 맞춥니다. 작은 화면은 메뉴·표 안에서 가로 스크롤합니다.
- 구역 탭, 국내 주식의 검색·필터 입력 줄과 표 제목은 페이지 스크롤 중 유지합니다. 큰 제목·자산 요약 전체를 고정하거나 별도 세로 스크롤 영역을 만들지 않습니다.
- 표는 종목명을 왼쪽, 금액을 오른쪽, 짧은 상태를 해당 열 기준으로 맞추며 제목과 본문의 기준선을 일치시킵니다. 목록은 기본 20개, 50·100개 선택과 페이지 이동을 제공합니다.
- FOLIO 로고는 자산 현황으로 이동합니다. 화면 잠금은 상단, 주문 인증은 사이드바, 설정·계정은 사이드바 하단에 둡니다.
- 전체 자산 가리기는 내 자산에서만 제공합니다. 각 가리기 버튼은 해당 제목 옆에 두며 실제 값 대신 대체 표시를 사용합니다. 브라우저에는 가림 선택만 저장합니다.
- 비밀번호·PIN·연결 변경은 팝업에서 수행합니다. 비밀번호·PIN 팝업은 중복된 상단 닫기 없이 하단 취소를 사용합니다. 저장 중 중복 제출을 막습니다.

색·글꼴·메뉴만 시안에서 가져오는 것이 아니라 실제 조회·주문·인증 흐름과 연결합니다. 사용자 화면에는 개발용 판단 이력이나 과거 연습 주문 컨트롤을 노출하지 않습니다.

## 종목 검색

상단 검색은 직접 입력창과 자동완성 목록입니다. `/` 키는 포커스를 옮기며 다른 입력창에서 타이핑 중이면 가로채지 않습니다. 방향키로 후보를 탐색하고 Enter로 선택하며 Esc·외부 클릭으로 닫습니다.

설정 대상 종목·마켓·리서치 기업 찾기·ETF 찾기는 같은 서버 검색 규칙을 사용합니다. 뉴스 키워드와 저장한 목록 안의 필터는 별도 기능입니다.

| 입력 | 예시와 동작 |
|---|---|
| 이름·코드 | 삼성전자, 삼성, 005930 |
| 초성 | ㅅㅅㅈㅈ, ㅅㅅ. 모든 한글 종목명의 초성을 계산 |
| 두벌식 한영 전환 | tt → ㅅㅅ, tkatjdwjswk → 삼성전자. 이름·초성의 키보드 문자열 검색 |
| 등록된 영어·별명 | 삼전·Samsung, 현차·Hyundai, Hynix 등. 대소문자·공백·전각 문자 정규화 |

정확한 이름·코드·등록 별명 일치를 우선하고 부분 이름·키보드·초성 후보를 뒤에 표시합니다. 같은 일치 수준에서는 선택한 정렬을 유지합니다. 짧은 입력은 여러 종목에 해당하므로 정식 이름·코드를 보여주고 자동 선택하지 않습니다.

선택용 검색은 캐시된 종목 목록에서 찾아 현재가 요청을 생략합니다. 계산한 검색 문자열은 재사용하고 화면에서는 입력 대기·이전 요청 취소·응답 순서 검사를 적용합니다. 시세·차트 요청은 검색 목록과 분리하며 이전 차트 요청을 취소합니다.

별명은 [stock_search.py](../../auto_trader/stock_search.py)의 `STOCK_ALIASES`에 코드별로 추가합니다. 현재 주요 11종목의 영어·한글 표기와 삼전·현차를 등록했습니다. 보통주·우선주와 유사 회사명 오연결을 확인하고 테스트를 추가한 뒤 서버를 재시작합니다. 외부 AI 호출·자동 학습은 사용하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_stock_search tests.test_toss -q
```

검증 대상은 별명·초성·두벌식·영어·일치 우선순위·중복·필터·페이지 구분·미등록 표현·외부 요청 생략입니다. 실행 위치는 프로젝트 루트입니다.

## 기업 아이콘과 무료 자산

- 기업 로고 4개는 로컬 파일로 제공하며 나머지는 짧은 이름 아이콘으로 대체합니다. 보유·관심·탐색·주문·종목 목록·상단 검색에서 사용합니다. 전체 기업 로고 API를 연동한 기능은 아닙니다. [기업 로고 출처](../../auto_trader/static/company-logos/SOURCES.md)를 확인합니다.
- Pretendard Variable 1.3.9와 Lucide static 0.468.0을 로컬 제공해 외부 글꼴·아이콘 서버에 의존하지 않습니다. [글꼴 라이선스](../../auto_trader/static/preview/vendor/PRETENDARD-LICENSE.txt), [아이콘 라이선스](../../auto_trader/static/preview/vendor/LUCIDE-LICENSE.txt)를 배포에 함께 둡니다.
- 레이아웃과 동작은 FOLIO 기능에 맞게 작성했습니다. 템플릿에 맞추기 위해 주문·한도·인증 기능을 제거하지 않습니다.

## 실제 자산 차트의 기준

인증된 자산 조회가 성공하면 사용자·계좌별 분당 관측을 `live_asset_history`에 저장합니다. 최근 366일 내 한국시간 날짜별 마지막 기록으로 차트를 표시합니다. 화면을 닫으면 이 조회 기반 수집은 멈춥니다.

자료가 없거나 한 날짜만 있으면 수집 시작 안내를 표시하며 예시 가격으로 채우지 않습니다. 총자산에는 입출금도 반영되므로 수익률 차트로 설명하지 않습니다. 자산 구성은 보유 평가금액과 원화 주문 가능 금액을 사용하고 외화 현금을 임의 환산해 합산하지 않습니다. 가리기 선택은 차트·구성에도 적용합니다.
