# DAY-01 손실 분석 독립 검토 (Claude Code)

작업 기록: [20261112-Claude-DAY01-loss-analysis-review](../plans/ai-tasks/20261112-Claude-DAY01-loss-analysis-review.md)

상태: **최종 — Codex 손실 분석(116개 왕복: A 48·B 68)을 원시 체결 원장에서 독립적으로 재도출한 값과 대조했고 불일치는 0건이다.** 이 문서에는 "대기 중" 상태가 남아 있지 않다. 분석은 진단이며 추천이 아니다. 재생·반사실 거래·최적화·개선안 구현은 하지 않았고 거절된 후보의 가상 수익은 산출하지 않았다. 모든 수치는 21 정규일·고정 22종목·가상 연구 추정(사후 추정 시가 체결, 1주 가정)에서 관측된 분포이며 **인과 증명이 아니고** 수익성·물리 체결·"비용 때문만의 손실"·"B가 더 낫다"는 주장을 하지 않는다.

## 1. 결론 요약

- **확정 사실(원시 원장에서 재현됨)**: 순손실의 85.0%(A)·90.6%(B)는 가정된 거래 비용이고 기준가 기준 총손익은 거의 0(왕복당 약 −35원)이다. 손실의 **주된 기여는 STOP 청산**이며 STOP 청산 왕복은 전부 순손실이다(A 32/32·B 41/41). 다만 순손실이 STOP에서만 나온 것은 아니다: B의 시간 청산(SESSION_LIQUIDATION) 9건 중 3건도 개별적으로 순손실이며(그룹 합계는 +532.65라 개별 손실이 가려진다), STOP이 곧 총손실을 뜻하지도 않는다(STOP 중 총손익 ≥ 0인 왕복이 있음). 손실은 날짜·종목·몇몇 거래에 몰리지 않는다. A/B의 차이는 전부 서로 다른 진입 집합이다.
- **UNKNOWN / 추가 데이터 필요**: 수집 지연·근사 VWAP·설정 수량 용량이 결과에 준 영향의 크기와 방향, 거절 후보의 수익, 거래량, 실제 중개사 비용.
- **독립 전향·표본 외 가설**: 같은 데이터로 최적화하지 않고 미리 선언해 앞으로 검증할 항목(5절).
- 따라서 **"비용만이 원인이다" 또는 "신호가 우위다/열위다"라는 결론은 내리지 않는다.** 총손익이 0 근처라는 사실과 비용이 가정값이라는 사실을 함께 말할 수 있을 뿐이다.

## 2. 방법과 대조 범위

1. 원시 체결(`multiday-A/B/trades.json`, 96·136건)을 체결 시각·종목 순으로 종목별 FIFO로 짝지었다(모든 수량 1, 부분 체결·잔량 0).
2. 왕복마다 비용 브리지 `총손익(기준가) − 불리한 슬리피지 − 수수료 − 세금 = 순손익`(= 매수 `cash_delta` + 매도 `cash_delta`)을 정확히 검증했다. 체결가는 이미 슬리피지를 포함하므로 이중 계산이 없다.
3. Codex 산출물(왕복 JSON/CSV, 발견 JSON, 후보 원장, A/B 비교, 후보 전이, 무결성 기록)을 읽고 **왕복 단위로 필드별 대조**했다: 종목·진입/청산 추정 시각, 총손익, 슬리피지, 수수료, 세금, 순손익, 청산 사유, 모델 보유 시간, 정산(관측) 보유 시간. 116개 왕복 **필드 불일치 0**, Codex 자체 브리지·슬리피지 반영 총손익 검증도 0건 실패.
4. 통계(건수·승패·평균·중앙값·payoff·표본 손익분기 승률), 청산 유형, 진입 신호 30분 구간, 청산(추정·정산) 30분 구간, 보유 구간 6개, 종목 22·날짜 21 분포를 독립 재계산해 대조했다(불일치 0).
5. 후보 원장(481건 × 2)과 `reasons.json`의 사유 집계, A/B 전이 표의 한계 분포, 승인 후보 가격 역산, 기록된 거절 6건 가격, 무결성 해시를 대조했다.
6. 이번 단계에서 새로 한 것은 읽기 전용 파싱·`Decimal` 계산뿐이다. 테스트는 재실행하지 않았다(이전 259개는 이번 단계의 신선한 통과가 아님).

## 3. 독립 재계산 결과 (모두 Codex와 일치)

비용 비중(순손실 대비): A 85.0%, B 90.6%. 비용 안에서 세금이 약 60.8%. **인과 해석의 한계**: 이 비중은 회계적 분해이며 비용 요율(수수료 0.015%·매도세 0.2%·슬리피지 양방향 0.05%)이 **가정이고 중개사 요율로 검증되지 않았다**. 비용을 없애면 순손익이 총손익(−1,800/−2,350)이 된다는 산술일 뿐, 신호에 우위가 있다는 뜻이 아니다. 총손익 자체가 음수이며 표본은 21일·48~68건이다. 또 총손익 > 0이지만 순손익 ≤ 0인 왕복이 A 2건·B 3건이어서 비용이 부호를 바꾸는 경우가 있다.

검증한 주장: "STOP은 모두 순손실"(A 32/32, B 41/41 참)이나 STOP이 항상 기준가 손실은 아니다(A 2건·B 2건은 총손익 > 0). 이는 모델의 STOP 청산이 손절 신호 후 **다음 추정 시가**에서 이뤄져 손절 가격 대비 회복·갭이 반영되기 때문이며 신호 품질의 직접 증거가 아니다. TARGET은 모두 순이익. 세션(시간) 청산은 A에서 전부 이익이었으나 B에서 9건 중 3건이 순손실이다. STOP 청산이 순손실의 주된 기여이며(모든 STOP 왕복이 순손실) TARGET·시간 청산의 그룹 이익이 이를 일부 상쇄한다(A 순손익 = −26,723.075 + 13,204.425 + 1,505.90 = −12,012.75). B의 시간 청산 그룹 합계 +532.65는 **개별 순손실 3건을 가린 값**이며(6건 이익, 3건 손실의 합), 따라서 시간 청산도 순손실이 될 수 있다.

### 3.6 A/B 거래 구성

공통 38건(진입 키 동일, 청산 동일; 같은 진입인데 청산이 다른 경우 0): A·B 모두 순 −5,425.80. A만 10건 −6,586.95. B만(추가) 30건 −19,601.575. 순손익 차이 −13,014.625는 전부 서로 다른 진입 집합에서 온다. B가 주문 한도가 풀려 가격이 큰 종목을 포함하고 일부 A 진입이 B의 슬롯·대기 상태로 제외되었다. 후보 전이 표의 A 한계·B 한계 합이 각각 481로 일치하고 A의 `ORDER_AMOUNT_LIMIT` 250건은 B에서 승인 24·이미 진입 54·지연 위험 3·슬롯 38·종목 한도 131로 이동한다. 절대 손실 B가 A의 약 2.08배인 것은 거래 수·종목 구성 때문이며 ROI·MDD가 작아 보이는 것은 분모 10배 효과다. **단순 ROI 개선 주장은 하지 않는다.**

### 3.7 진입 후보 481건 — 승인·거절과 사용 가능한 필드

- 사유 매핑: 후보 원장의 상태 집계 = `reasons.json`의 사유 집계(A: 승인 48·주문 한도 250·이미 진입/대기 128·지연 위험 16·슬롯 39 / B: 승인 68·종목 한도 134·이미 진입/대기 177·슬롯 84·지연 위험 18). 481건은 고유 후보가 아니라 의사결정 이벤트이며 같은 종목·날의 반복 평가가 128/177건이다.
- **가격 라벨 감사**: 승인 48/68건의 "알려진 신호 가격"은 저장된 신호 예약(`reservation.amount`)을 `금액 = 가격 × 1.0005 × 수량`으로 **역산한 값**이며 직접 시장 사실이 아니다(엔진의 신호 시점 최신 종가에서 결정적으로 계산된 값). 116건 전부 역산 가격이 정수 KRW이고 `가격×1.0005`가 저장된 금액과 정확히 같으며, 수수료는 `floor(금액×0.00015)`, `현금 = 금액 + 수수료`와 일치해 **수수료 내림 모호성 없이 유일하게 역산**된다(인접 가격의 금액 간격이 ≥ 1.0005이므로 유일). Codex 원장의 가격과 내 역산이 불일치 0이고 라벨(`DERIVED_FROM_SIGNAL_RESERVATION_AND_FIXED_CONFIG`)이 정직하게 "역산"을 표시한다. 거절 후보 중 가격이 있는 6건은 2026-11-03 단일일 진단(저장된 원본 6개 진단)에서 오며 가격이 내가 원본 행에서 독립 감사한 값(1,420,000·222,500·1,418,000·221,250·222,250·222,500)과 정확히 같다. 나머지 거절·기타 후보(A 427·B 407)의 가격은 **UNKNOWN**(저장되지 않음), 거래량은 **전부 UNKNOWN**이다.
