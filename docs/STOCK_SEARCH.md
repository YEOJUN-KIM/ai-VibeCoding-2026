# 종목 검색

기준일: 2026-10-03. 공통 헤더에서도 입력 중 자동완성을 제공하고 `/` 키는 입력창에 초점을 맞춥니다. 검색 팝업을 열거나 Enter를 눌러야 조회되는 방식이 아닙니다.

설정의 대상 종목, 마켓 목록, 장기 리서치의 기업 찾기, ETF 찾기는 같은 서버 검색 규칙을 사용합니다. 뉴스 키워드 검색과 저장된 목록 안의 필터는 별도 기능입니다.

## 지원하는 입력

- 이름·종목 코드: 삼성전자, 삼성, 005930.
- 초성: ㅅㅅㅈㅈ, ㅅㅅ. 한글 완성형에서 초성을 자동 계산하므로 모든 종목에 적용됩니다.
- 두벌식 한영 전환 입력: tt → ㅅㅅ, tkatjdwjswk → 삼성전자. 이름의 키보드 문자열과 초성의 키보드 문자열 모두 검색합니다.
- 영어·별명: 삼성전자의 삼전·Samsung, 현대차의 현차·Hyundai, SK하이닉스의 Hynix 등 등록한 표현을 검색합니다. 대소문자·공백·전각 문자를 정규화합니다.

정확한 이름·코드·등록된 별명이 가장 먼저 나옵니다. 부분 이름, 키보드 입력·초성 후보가 뒤따르며 같은 일치 수준에서는 사용자가 고른 정렬을 유지합니다. 짧은 입력은 여러 종목에 해당할 수 있습니다. 결과에는 정식 종목명과 코드를 표시하며 자동으로 종목을 선택하지 않습니다.

## 별명 확장

`auto_trader/stock_search.py`의 `STOCK_ALIASES`에 종목 코드별 표현을 추가합니다. 현재 주요 11종목의 영어 이름·한글 표기와 삼전·현차를 등록했습니다. 별명을 추가할 때 같은 기업의 보통주·우선주, 비슷한 이름의 다른 회사로 잘못 연결되지 않는지 확인하고 테스트를 추가합니다. 수정 후 서버를 재시작합니다. AI 학습이나 검색 중 외부 AI 호출은 사용하지 않습니다.

계산된 이름·초성·키보드 문자열은 메모리 캐시로 재사용합니다. 선택용 검색은 현재가 요청을 하지 않고 기존 종목 목록에서 찾습니다. 마켓·ETF의 시세 조회 정책과 시장·유형 필터, 페이지 구분은 유지합니다.
