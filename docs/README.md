# FOLIO 문서 안내

기준일: 2026-10-04. 개인용 Windows 로컬 투자 웹앱의 소개, 구현 상태와 다음 작업을 정리합니다. 기본 기능은 대부분 구현했으며 데이터 축적·모의 운용 검증 단계입니다. 매매용 모델 학습과 실제 자동매매는 아직 완료되지 않았습니다.

## 처음 읽는 순서

1. [프로젝트 소개](PROJECT_OVERVIEW.md): 무엇을 만들었고, 어떤 문제를 어떻게 해결했는지. 포트폴리오·발표의 출발점입니다.
2. [현재 구현 상태](CURRENT_STATE.md): 실제 제공 기능과 알려진 제한.
3. [다음 작업](ROADMAP.md): 지금 확인할 일, 데이터가 모인 뒤 할 일, 릴리스 전 확인.

실행하려면 [Windows 설치·실행 안내](guides/INSTALL_WINDOWS.md), 변경된 내용을 찾으려면 [주요 변경 이력](CHANGELOG.md)을 읽습니다.

## 이 폴더를 정리하는 기준

- 현재 동작은 현재 상태, 안정적인 요구사항은 제품 기준, 앞으로 할 일은 로드맵에 씁니다. 상세 설명을 여러 문서에 복사하지 않고 링크합니다.
- 보류 아이디어는 계획 폴더에만 두고, 착수하기로 결정한 범위만 로드맵으로 옮깁니다.
- 기능이 바뀌면 현재 상태·해당 상세 문서·변경 이력을 함께 맞춥니다. 완료한 로드맵 항목은 이력으로 옮기거나 남은 검증만 남깁니다.
- 구현, 자동 테스트, 예시 데이터 화면 확인, 실제 계좌·장중 운용 확인을 구분합니다. 과거 테스트 건수와 데이터 건수에는 확인 날짜를 붙입니다.
- 포트폴리오에는 구현·확인한 내용만 결과로 씁니다. 미학습 모델, 미구현 기능과 수익 개선 가설은 계획으로 표시합니다.
- API 키·비밀번호·PIN·개인 계좌 기록·백업 원본을 공개 문서나 Git에 넣지 않습니다.

검색·디자인 미리보기 설명은 화면·검색 설계로 통합했습니다. 일반적인 바이브 코딩 용어 메모와 별도 머신러닝 포트폴리오 안내는 덜어내고, 프로젝트에 필요한 개발 방식·증거 정리는 프로젝트 소개에 모았습니다.
