# 자동매매 프로그램 개발 현황

## 프로젝트 정보

- 개발 시작일: 2026-09-23
- 마지막 수정일: 2026-09-26
- 현재 단계: 국내 종목 탐색과 뉴스·리서치 1차 완성, 다음 핵심 기능 선정 단계
- 현재 운영 범위: PAPER 모의매매, LIVE 계좌 조회 전용

## 최종 목표

국내·해외 주식의 시세와 계좌를 한곳에서 확인하고, 모의매매부터 실제 자동매매까지 안전하게 실행할 수 있는 개인용 투자 관리 프로그램을 만든다.

단기 자동매매뿐 아니라 장기투자 분석, 종목 탐색, 관심 종목, 해외주식, 뉴스·산업 분석까지 하나의 웹 서비스에서 관리하는 것을 목표로 한다.

## 현재까지 완성한 기능

### 기반 시스템

- Python과 FastAPI 웹 서버
- PostgreSQL 데이터베이스
- 환경변수를 이용한 비밀정보 분리
- Swagger API 문서
- PAPER와 LIVE 페이지 분리

### 로그인과 보안

- 단일 관리자 로그인
- scrypt 비밀번호 해시
- 로그인 실패 잠금
- PostgreSQL 로그인 세션
- HttpOnly 쿠키와 CSRF 보호
- LIVE용 6자리 PIN
- PIN 실패 잠금과 5분 인증 유효시간

### PAPER 모의매매

- 가상자금 기반 모의계좌
- 수동 모의 매수·매도
- 이동평균 단기 자동매매 전략
- 주문·체결·보유종목·손익의 프로세스 메모리 관리
- 수수료와 세금 모의 계산
- 연습 기록 초기화

### 위험 관리

- 보수적, 기본, 직접 설정 프리셋
- 1회 최대 주문 금액
- 종목별 최대 투자 금액
- 전체 최대 투자 금액
- 최소 현금 보유 비율
- 일일 손실 한도
- 일일 주문 횟수
- 일일 수익 목표
- 수동·자동 주문의 공통 서버 검사

### 토스증권 LIVE 연동

- OAuth 2.0 액세스 토큰 발급
- 허용 IP 및 API 연결 확인
- 실제 계좌 자동 선택
- 계좌번호 마스킹
- 실제 보유주식 조회
- 매입금액·평가금액·손익 조회
- 5초 간격 자동 갱신
- 브라우저 탭이 숨겨지면 자동조회 중지
- 토스 API 비율 단위 변환 검증
- 원화·달러 주문 가능 금액과 추정 총자산 표시

### 국내주식 탐색과 상세

- 국내주식 마켓 스캐너와 상세 페이지 연결
- PostgreSQL 기반 사용자별 관심 종목과 현재가·등락률·인기 순위 표시
- Private Trading Desk 공통 화면 테마
- 로그인 후 LIVE 실제계좌 우선 진입
- 향후 페이지 확장을 위한 공통 워크스페이스 내비게이션
- 국내 휴장일에는 최근 거래일 평가손익과 기준일 표시
- 코스피·코스닥 전체 종목 목록과 검색·필터·정렬·관심종목 연동
- 전체 종목 목록의 시가총액·거래대금과 그라데이션·글로우 스파크라인
- 1일·7일·1개월·3개월·1년 기간별 목록 스파크라인과 조회 캐시
- 종목명 클릭 상세 이동과 기간 선택형 캔들·라인·거래량 차트(기본 1일)
- 1일·7일·1개월 분봉 페이지 수집·구간 집계와 3개월·1년 일봉 차트
- 상세 차트의 마우스 십자선, 날짜·시간·OHLC·등락률·거래량 툴팁
- MA5·MA20 이동평균선, 현재가 기준선과 장중 가격 공백 표시
- 상세 화면의 시·고·저·종, 시가총액, 거래대금, 거래량, 상장주식수 표시
- LIVE 계좌 화면의 중복 종목 검색을 국내주식 전용 페이지로 통합
- 목록 차트 묶음 로딩, 캐시와 서버 시작 시 종목 목록 예열로 초기 응답 개선
- LIVE·PAPER·국내주식·종목 상세 화면의 제목과 설명 문구 정리

### 뉴스·리서치 1차

- 뉴스·리서치 검색 페이지와 제목 기반 보도 흐름 요약
- 종목 상세 화면의 종목별 최근 뉴스와 뉴스·리서치 연결
- 유사한 기사 제목을 대표 기사와 관련 기사로 묶는 이슈 그룹
- 약한 표현·단순 숫자 제거와 종목 별칭 정규화를 적용한 키워드 정리
- 기사 수·매체 수·최신 시각으로 선정한 상단 핵심 이슈 카드

## 현재 페이지

- `/paper`: PAPER 모의매매 및 위험 한도 설정

## 중요한 안전 원칙

- PAPER와 LIVE 화면 및 데이터를 명확히 분리한다.
- 실제 주문 전에 로그인과 PIN을 다시 확인한다.
- 모든 실제 주문은 서버의 투자 한도 검사를 통과해야 한다.
- 자동매매가 산 주식과 사용자가 기존에 보유한 주식을 구분한다.
- 오류나 통신 단절이 발생하면 신규 주문을 차단한다.
- 주문 요청 ID를 사용하여 중복 주문을 방지한다.
- AI 분석을 확정적인 매수·매도 지시로 표현하지 않는다.
- 뉴스·분석에는 출처, 근거, 시각과 불확실성을 표시한다.
- 비밀키와 액세스 토큰을 화면·로그·Git에 노출하지 않는다.

## 결정이 필요한 사항

- 장기투자 평가 기준과 가중치
- 뉴스와 뉴스레터 수집 출처
- 실제 주문의 최종 승인 단계
- 수익 목표 도달 시 신규 주문만 막을지 자동매매 보유분도 매도할지
- 국내·해외 투자 한도 분리 방식
- 추가할 자동매매 전략과 전략 선택 방식
- 토스 인베스트 바로가기의 위치와 표시 방식
- 알림 수단과 알림이 필요한 이벤트
- AI 뉴스 브리핑·개별 기사 요약 사용 여부와 월 비용 한도 (`AI_NEWS_ENABLED=false`로 구현 보류)
- 요약에 사용할 수 있는 기사 본문 제공처와 이용 권한 범위

## 문서 관리 방법

- 기능을 완성하면 `현재까지 완성한 기능`과 `변경 기록`에 추가한다.
- 다음 작업이 바뀌면 `다음 핵심 목표`의 순서를 수정한다.
- 새로운 아이디어는 바로 구현하지 않아도 `추가 구상`에 먼저 기록한다.
- 결정되지 않은 사항은 `결정이 필요한 사항`에 남긴다.
- 문서를 수정할 때 `마지막 수정일`도 함께 갱신한다.
