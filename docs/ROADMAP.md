# 자동매매 프로그램 개발 현황

## 프로젝트 정보

- 개발 시작일: 2026-09-23
- 마지막 수정일: 2026-09-23
- 현재 단계: 토스증권 실제 계좌 읽기 연동 완료, LIVE 주문 준비 단계
- 현재 운영 범위: PAPER 모의매매, LIVE 계좌 조회 전용

## 최종 목표

국내·해외 주식의 시세와 계좌를 한곳에서 확인하고, 모의매매부터 실제 자동매매까지 안전하게 실행할 수 있는 개인용 투자 관리 프로그램을 만든다.

단기 자동매매뿐 아니라 장기투자 분석, 종목 탐색, 관심 종목, 해외주식, 뉴스·산업 분석까지 하나의 웹 서비스에서 관리하는 것을 목표로 한다.

## 현재까지 완성한 기능

### 기반 시스템

- Python과 FastAPI 웹 서버
- PostgreSQL 데이터베이스
- 환경변수를 이용한 비밀정보 분리
- Swagger API 문서
- PAPER와 LIVE 페이지 분리

### 로그인과 보안

- 단일 관리자 로그인
- scrypt 비밀번호 해시
- 로그인 실패 잠금
- PostgreSQL 로그인 세션
- HttpOnly 쿠키와 CSRF 보호
- LIVE용 6자리 PIN
- PIN 실패 잠금과 5분 인증 유효시간

### PAPER 모의매매

- 가상자금 기반 모의계좌
- 수동 모의 매수·매도
- 이동평균 단기 자동매매 전략
- 주문·체결·보유종목·손익의 프로세스 메모리 관리
- 수수료와 세금 모의 계산
- 연습 기록 초기화

### 위험 관리

- 보수적, 기본, 직접 설정 프리셋
- 1회 최대 주문 금액
- 종목별 최대 투자 금액
- 전체 최대 투자 금액
- 최소 현금 보유 비율
- 일일 손실 한도
- 일일 주문 횟수
- 일일 수익 목표
- 수동·자동 주문의 공통 서버 검사

### 토스증권 LIVE 연동

- OAuth 2.0 액세스 토큰 발급
- 허용 IP 및 API 연결 확인
- 실제 계좌 자동 선택
- 계좌번호 마스킹
- 실제 보유주식 조회
- 매입금액·평가금액·손익 조회
- 5초 간격 자동 갱신
- 브라우저 탭이 숨겨지면 자동조회 중지
- 토스 API 비율 단위 변환 검증

## 현재 페이지

- `/paper`: PAPER 모의매매 및 위험 한도 설정
- `/live`: 실제 토스증권 계좌 조회와 LIVE PIN 인증
- `/login`: 관리자 로그인
- `/docs`: FastAPI API 문서

## 계획 중인 페이지 구조

- `/paper`: 모의매매
- `/account`: 내 실제 계좌
- `/stocks`: 국내 주식 탐색
- `/long-term`: 장기투자 분석
- `/global`: 해외주식
- `/news`: 뉴스·리서치
- `/settings`: API·보안·전략 설정

페이지 이름과 주소는 실제 화면을 만들 때 변경할 수 있다.

## 중요한 안전 원칙

- PAPER와 LIVE 화면 및 데이터를 명확히 분리한다.
- 실제 주문 전에 로그인과 PIN을 다시 확인한다.
- 모든 실제 주문은 서버의 투자 한도 검사를 통과해야 한다.
- 자동매매가 산 주식과 사용자가 기존에 보유한 주식을 구분한다.
- 오류나 통신 단절이 발생하면 신규 주문을 차단한다.
- 주문 요청 ID를 사용하여 중복 주문을 방지한다.
- AI 분석을 확정적인 매수·매도 지시로 표현하지 않는다.
- 뉴스·분석에는 출처, 근거, 시각과 불확실성을 표시한다.
- 비밀키와 액세스 토큰을 화면·로그·Git에 노출하지 않는다.

## 결정이 필요한 사항

- 장기투자 평가 기준과 가중치
- 뉴스와 뉴스레터 수집 출처

- 수익 목표 도달 시 신규 주문만 막을지 자동매매 보유분도 매도할지

- 추가할 자동매매 전략과 전략 선택 방식
- 토스 인베스트 바로가기의 위치와 표시 방식
- 알림 수단과 알림이 필요한 이벤트

- 기능을 완성하면 `현재까지 완성한 기능`과 `변경 기록`에 추가한다.
- 다음 작업이 바뀌면 `다음 핵심 목표`의 순서를 수정한다.
- 새로운 아이디어는 바로 구현하지 않아도 `추가 구상`에 먼저 기록한다.
- 결정되지 않은 사항은 `결정이 필요한 사항`에 남긴다.
- 문서를 수정할 때 `마지막 수정일`도 함께 갱신한다.
