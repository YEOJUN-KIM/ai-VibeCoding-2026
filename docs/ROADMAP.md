# 데이터 축적 이후의 작업 로드맵

기준일: 2026-10-04

## 현재 단계

계정·증권 연결, 자산 조회, 종목 탐색, 장기 리서치, 모의매매, 휴장일·거래 시간 연동과 Windows 간편 실행 등 현재 계획한 기본 기능은 대부분 구현했습니다. 당장은 새 화면이나 기능을 늘리기보다 데이터를 쌓으면서 실제 동작을 확인하고 발견한 문제를 수정합니다. 기본 기능 구현 완료는 모델 검증이나 실제 자동매매 구현 완료를 뜻하지 않습니다.

완료 이력은 [CHANGELOG.md](records/CHANGELOG_HISTORY.md), 현재 기능과 제한은 [CURRENT_STATE.md](CURRENT_STATE.md), 머신러닝 세부 진행은 [구현 현황](machine-learning/CURRENT_PROGRESS.md)을 기준으로 합니다.

## 1. 데이터 축적과 모의 운용 확인 — 지금 할 일

- [ ] 서버를 유지해 종목·국내 지수·환율·미국 지표 데이터를 모으고 일일 품질 보고서로 누락·지연·중복을 확인합니다. 서버가 켜져 있으면 원본 수집은 모의 전략 정지 중에도 진행됩니다.
- [ ] 모의계좌에서 전략을 시작해 판단·주문·청산 기록을 쌓고 상태와 손익 표시를 확인합니다. 서버 재시작 후에는 전략을 직접 다시 시작해야 합니다.
- [ ] 다음 장중에 휴장·운영 시간 대기에서 정상 감시로 전환되는지, 시장 종료와 확인 실패 때 판단·체결이 대기하는지 관찰합니다. 캘린더 연동과 종료 경계 검사는 구현·자동 테스트 완료입니다.
- [ ] 주간 첫 프리셋 미리보기에서 후보 교체와 저장 전략 보존을 실제 확인합니다. 주간 재사용과 초안 적용은 구현·테스트 완료입니다.
- [ ] 장기 추천 예약 분석의 실행·목록 교체·기준일과 저장한 기업 제외를 실제 확인합니다. 현재 로컬 개발 설정은 09:10(KST), 코드·환경 예시 기본값은 04:30입니다.
- [ ] 계좌 전환·설정 변경·재시작 복원에서 불편이나 오류가 발견되면 수정합니다. API 등록 후 재시작에도 연결·자산 조회가 유지되는 것은 현재 PC에서 확인했으며 새 PC·키 파일 유실 복구는 별도 검증합니다.

최소 5거래일, 가능하면 20거래일 이상은 초기 연구용 데이터 확보 목표입니다. 일수만 채웠다고 학습 준비나 수익성이 검증되는 것은 아니며 종목별 자료 범위·품질·거래 표본을 함께 확인합니다. 실제 누적 건수는 최신 보고서로 확인하고 과거 문서의 건수를 현재 값으로 취급하지 않습니다.

## 2. 모델 학습과 모의매매 비교 — 데이터가 준비된 뒤

1. 판단 당시 알 수 있었던 자료만 결합하고 비용을 반영한 학습 정답을 만듭니다.
2. 구현된 이동평균 기준선 백테스트를 여러 거래일로 검증합니다. 현재는 하루 일부 자료의 첫 실행까지 확인했습니다.
3. 시간순으로 학습·검증·시험 구간을 나눠 첫 단순 모델을 학습하고 기존 전략과 비교합니다.
4. 검증한 모델의 실시간 판단을 모의매매에 연결하고 모델 미사용 전략과 비교합니다. 모델 학습과 실시간 모델 판단 연결은 아직 구현 완료가 아닙니다.
5. 순손익·낙폭·비용·거래 수와 여러 시장 구간의 결과를 보고 모델 사용 여부를 결정합니다. 기존 전략보다 나아지지 않으면 실계좌 전환 대신 원인을 검토합니다.

학습용 뉴스·공시의 시점별 원본 저장과 추가 결합은 첫 가격·시장 기반 모델 이후의 선택 확장입니다. 화면의 뉴스·공시 조회 기능과 구분합니다.

## 3. 실제 자동매매 연결 — 별도 구현·검증 단계

현재 실제 계좌 기능은 자산 조회와 안전장치를 적용한 수동 주문입니다. 모델 학습이 끝나도 실제 자동매매가 바로 활성화되지는 않습니다.

- [ ] 모의 검증을 통과한 전략·모델의 실제 주문 실행 경로를 구현합니다.
- [ ] 중복 주문 방지, 접수·체결 대조, 부분 체결·취소와 미확정 주문 처리, 장애·재시작 복구를 검증합니다. 기존 수동 주문의 저장·대조 기능을 자동 운용에서도 확인해야 합니다.
- [ ] 손실 제한·긴급 정지·거래 시간 확인과 주문 인증·서버 안전 잠금을 함께 검증합니다.
- [ ] 사용자가 실제 운용 여부와 범위를 결정한 뒤 제한된 범위로 시작합니다.

세부 후보는 [BACKLOG.md의 실제 자동매매](plans/BACKLOG.md#live-자동매매)에 기록합니다. 이 단계는 현재 머신러닝 과정의 완료 조건과 별개입니다.

## 릴리스 전 확인 — 현재 기능 추가와 구분

- [ ] 개발용 모의매매 투자 한도 예외를 제거하고 장기 분석 예약 기본 시각과 운영 일정을 확인합니다.
- [ ] 실제 주문 서버 안전 잠금 기본값과 비밀값·로컬 거래 기록의 배포 제외를 확인합니다.
- [ ] 전체 테스트와 주요 화면 수동 점검을 진행합니다. 개별 기능 테스트를 전체 릴리스 검증으로 간주하지 않습니다.
- [ ] 다른 PC의 최초 설치·DB 권한·키 재등록·화면 복원을 확인합니다. 현재 PC의 간편 실행·중복 재사용·정상 종료와 2026-10-03 임시 DB 복원은 확인했습니다.
- [ ] 정기 백업 자동 실행·외부 보관·암호화 방식을 정하고 검증합니다.

## 이후 검토 — 지금은 구현하지 않음

휴대폰 상태 확인·원격 정지, 설치형 배포, 설정 이동·동기화와 참여자 데이터 수집은 [배포·모델 개선 계획](plans/DEPLOYMENT_AND_MODEL_PLAN.md)에 기록합니다. 휴대폰 연결은 집 PC·프로그램·DB·인터넷이 유지되고 절전 상태가 아니라는 전제입니다. 앱 형식과 외부 연결 방식은 추후 사용자와 결정하며 지금은 앱 제작·외부 접속 개방·토스 로그인을 진행하지 않습니다.

사용자 화면에는 개발·점검용 판단 이력을 다시 추가하지 않습니다. 학습용 판단 DB 저장은 유지하고 사용자는 현재 판단과 주문 기록을 확인합니다.
