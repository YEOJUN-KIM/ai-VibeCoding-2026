## 완료 판단

- 외부 API가 느리거나 한도를 초과해도 중복 호출이 폭증하지 않는다.
- PAPER와 LIVE 상태가 혼동되지 않고 실제 주문은 모든 안전 조건을 통과해야 한다.
- 장기 추천의 기준일과 근거가 보이며 내 관찰 목록과 자동 추천이 섞이지 않는다.
- 서버 재시작 후 영구 저장 대상은 복구되고 메모리 대상은 초기화 사실이 명확히 안내된다.
