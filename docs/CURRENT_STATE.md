# 현재 구현 상태

기준일: 2026-10-04

- 사용자 화면은 모의매매의 현재 판단과 주문 기록을 제공합니다. 개발·점검용 판단 이력 조회 화면은 제공하지 않습니다. 머신러닝용 판단 기록의 DB 저장과 기존 기록은 유지하며, 인증된 소유 계좌 범위의 내부 조회 기능은 개발·점검 용도로만 남겨둡니다.

## 진행 단계

현재 계획한 기본 기능은 대부분 구현했습니다. 당장은 기능 확장보다 데이터 축적·품질 확인·장중 모의 운용과 오류 수정을 진행합니다. 이동평균 기준선 백테스트의 첫 실행은 확인했지만 다일 검증, 첫 모델 학습, 실시간 모델 판단 연결과 실제 자동매매는 남아 있습니다. 상세 순서는 [ROADMAP.md](ROADMAP.md)와 [머신러닝 구현 현황](machine-learning/CURRENT_PROGRESS.md)을 따릅니다.

휴장일·거래 시간 제한은 모의매매 엔진에 적용했습니다. 별도의 머신러닝 원본 수집 작업이 동일한 캘린더로 실행된다는 뜻은 아닙니다. 수집 일정과 자료 품질은 머신러닝 문서를 기준으로 확인합니다.

## 운영 방향·계정 소유 관계

- 현재는 개인용 Windows 로컬 웹앱으로 운영한다. 다중 사용자 가입·공개 서버 운영은 확장하지 않는다. 집 컴퓨터가 켜져 있을 때 휴대폰으로 확인·정지하는 앱은 계획만 기록했으며 구현하지 않았다. 앱 형식과 외부 연결 방식, 토스 로그인 도입은 보류한다.
- 기존 환경 설정의 증권 연결과 두 모의계좌는 최초 관리자에게 귀속한다. 다른 사이트 사용자는 환경 설정의 키를 상속하지 않는다. 사용자별 증권 클라이언트·모의계좌·실행 상태·투자 한도·선택한 계좌를 분리한다.
- 계정 설정의 연결 등록·변경 팝업에서 API 키를 확인 후 `.local-secrets/broker-{user_id}.bin`에 Windows DPAPI로 암호화해 저장한다. DB에는 연결 소유 관계·계좌 정보만 저장하고, API 키·Secret·암호화된 키는 저장하지 않는다. 비밀 파일 폴더는 Git에서 제외한다. Windows 사용자/컴퓨터를 옮기면 새 키를 재등록해야 한다. 기존 환경 설정 키는 `.env`를 계속 사용한다.
- 초기 DB 암호화 키 저장 컬럼이 존재하면 로컬 암호화 파일로 이전한 뒤 해당 컬럼과 제약을 제거한다. 현재 실제 DB에는 이전할 API 키가 없었다. DB만 복사한 경우 로컬 키가 없으면 해당 연결을 미연결로 처리한다. 로그인 화면은 DB 연결만 요구하며 API 키가 없어도 로그인할 수 있다. 키가 미설정·유실된 사용자는 로그인 후 계정 설정으로 이동해 재등록한다.
- 같은 증권 계좌의 중복 연결과 연결한 계좌의 교체를 차단한다. 전략 실행 또는 실제 주문 진행 중에는 연결 변경을 막고, 변경 성공 시 주문 인증을 해제한다. 실제 주문 대조는 사용자와 계좌를 함께 기준으로 조회한다.
- 잔액·주문·전략은 유지하지만 서버 재시작 후 자동으로 전략을 시작하지 않는다.

## 사용자 화면

- 자산 현황: 실제 계좌 조회 성공 시 사용자·계좌별 분당 총자산 관측을 DB에 저장하고, 날짜별 마지막 기록으로 기간 차트를 표시합니다. 현재 보유·원화 주문 가능 금액의 자산 구성과 가리기 기능을 제공합니다. 공통 헤더 종목 검색과 로컬 기업 로고 4개·짧은 이름 아이콘을 연결했습니다.

- 공통 디자인: `theme.css`로 차콜 배경·바이올렛 강조·로컬 Pretendard 글꼴을 적용합니다. 데스크톱 주요 메뉴는 왼쪽, 페이지별 메뉴는 상단 탭으로 배치합니다. 모바일 주요 메뉴는 가로 스크롤로 유지합니다. 자산 현황·국내 주식·주요 뉴스로 명칭을 정리했으며 브랜드는 FOLIO를 유지합니다. 디자인 적용 전 정적 파일 백업과 검증 범위는 DESIGN_PREVIEW.md를 참고합니다.

- 종목 찾기: 이름·코드 외에 초성·두벌식 한영 입력, 주요 11종목의 영어·등록된 별명을 지원합니다. 정확한 일치를 먼저 보여주고 후보에는 정식 이름·코드를 표시합니다. 검색 규칙과 별명 추가 방법은 STOCK_SEARCH.md에 기록합니다.

- 로그인: 관리자 아이디·비밀번호 인증, 계정 저장소 준비 상태 안내. 증권사 연결은 로그인 조건이 아니며 공개 로그인 준비 확인에서 증권 API를 호출하지 않습니다. PIN은 화면 잠금 해제와 실제 주문 인증에 사용합니다.
- 설정: 계정·연결 → 자동매매 전략 → 투자 한도 순서입니다. 비밀번호·PIN·API 연결 변경은 각각 팝업에서 수행하며 시스템 탭은 제거했습니다. 새 비밀번호는 8~20자이고 PIN은 숫자 6자리입니다.
- 공통 구역 메뉴: 주요 페이지는 왼쪽 메뉴, 페이지 내부 구역은 상단 탭을 사용합니다. 작은 화면에서는 가로 스크롤 메뉴로 표시합니다.
- 국내주식: 종목 탐색, 관심종목, 시장 데이터 사전 로딩
- 검색: 종목 선택은 이름·코드 캐시에서 빠르게 조회하며 시세 요청을 생략합니다. 설정·마켓·리서치·ETF·뉴스에서 입력 변경과 최신 요청을 기준으로 이전 응답을 무효화합니다. 마켓은 조회 중 새 검색도 처리하고 이름·코드를 먼저 표시한 뒤 현재가를 갱신합니다. 종목 기본정보 캐시를 재사용하고 이전 차트 요청을 취소합니다. 한글 조합 중에도 검색 요청을 예약합니다.
- 종목 상세: 차트, 기업정보, 시장정보, 뉴스, 장기 리서치 분석, 실제 계좌 수동 주문
- 장기 리서치: 추천 기업과 저장한 기업을 분리해 표시
- 뉴스: 유사 주제를 묶어 한 이슈가 화면을 독점하지 않도록 정리하고 보도 흐름 요약에서 이슈별 기사 묶음으로 이동합니다.
- 전략 설정: 독립된 2열 입력 영역, 최근 선택한 3개 전략, 전체 전략 5열 검색 팝업, 상단 저장·삭제 버튼
- 기본 프리셋 영역은 처음에 접힌 안내로 표시하고 필요할 때 펼칩니다. 초안 적용 후 다시 접어 입력에 집중할 수 있습니다. 입력한 전략 요약을 표시하며 이동평균 기간·운영 시작/종료 관계 오류는 저장 전에 안내합니다. 익절·손절 설명은 비용 반영 기준으로 표시합니다.
- 새 전략·기본 프리셋의 운영 시간 기본값은 한국시간 08:00~20:00이며, 주간 프리셋의 새 전략 이름은 `인기 · MM/DD주` 또는 `가성비 · MM/DD주`로 제공한다. 기존 저장 전략은 유지한다.
- 기본 인기·가성비 프리셋: 월요일(KST) 기준 주간 첫 미리보기에서 후보 데이터를 갱신·DB 저장하고 같은 주에는 유지합니다. 팝업에서 예산별 후보·예상 수량을 확인하고, 열기 전에도 생성 시각·다음 갱신 기준일·데이터 상태를 표시합니다. 정해진 시각의 예약 갱신은 아니며 저장된 전략은 자동 변경하지 않습니다.
- 기본 프리셋은 시장·예산 조건을 통과한 후보를 거래대금 순위로 정렬해 최대 10종목까지 선정합니다. 미리보기에 조건 통과 수와 선정 수를 표시하고 후보가 10개보다 적으면 모두 제공합니다. 예산 변경은 같은 주간 후보 데이터에 적용합니다. 거래대금 순위는 수익성 평가 점수가 아닙니다. 최대 종목 수 변경 UI는 보류 작업이며 현재 시스템 탭은 제공하지 않습니다.
- PAPER: 보유 종목·계좌·전략·전략 판단·주문 기록·투자 한도 메뉴를 제공합니다. 계좌 카드를 눌러 전환하고 전략 선택(즉시 적용) → 실행 순서로 진행합니다. 상세는 별도 버튼으로 펼치며 초기화·실제 자산 복사는 계좌·전략 구역 아래의 계좌 관리에 둡니다. 마지막 선택 계좌와 계좌별 마지막 전략은 재시작 후 복원하지만 전략은 정지 상태입니다.
- PAPER 결과: 보유 표에서 담당 전략·관리 상태·전략별 수량과 청산 조건을 확인합니다. 전략 판단에는 최근 조회 시각과 종목별 감시·대기·주문 제한을 표시합니다. 주문 기록은 한국시간 날짜 범위·종목명/코드·매수/매도·상태로 필터하고 전략 이름·체결 금액·비용 반영 실현손익을 별도 열로 확인합니다. 이유와 수수료·세금·체결 차이는 상세로 펼치며 자동 갱신 시 열린 상세를 유지합니다. 거절 주문에는 체결가·금액·손익을 표시하지 않습니다.
- 전략 판단 상단은 현재 정지·운영 시간 대기·시세 대기·일부 종목 대기·공통 신규 매수 제한·정상 감시를 구분하고 이유와 다음 행동을 표시합니다. 정지 시 이전 시세 메시지 대신 정지 안내를 우선하며, 공통 한도 미도달이어도 개별 주문 한도는 추가 확인합니다.
- 종목별 판단에는 수수료·슬리피지를 포함한 예상 매수 비용과 예산 초과, 현금 부족, 실제 위험 한도, 전략 주문 횟수·재매수 대기 이유를 표시합니다. 실행 중의 최근 시세·미보유 종목에만 현재 제한을 계산하며 정지·오래된 시세에는 새 제한을 표시하지 않습니다. 실제 매수 시도 실패 이유도 판단·학습 기록에 남깁니다.
- 모의매매 공통 상태 줄에서 정지·긴급 정지·주말·설정 운영 시간 밖·API 요청 한도·시세 지연과 최근 시세 수신·조건 확인 시각을 한국시간으로 표시합니다. 성공한 조건 확인 시각은 화면 조회 시각과 구분하며 재시작·전략 변경 시 기록 전으로 초기화합니다. 서버 상태 조회 실패 시 마지막 기록임을 안내합니다. PAPER 자동 판단은 국내 통합시장 캘린더의 연속 거래 시간과 전략 설정 시간의 교집합에서만 실행합니다. 휴장·거래 시간 밖·단일가 구간·캘린더 확인 실패에는 매수와 청산 모두 대기하며 다음 거래 시작 시각을 한국시간으로 안내합니다.
- LIVE: 실제 계좌 자산 조회, 실제 주문 기록과 안전장치가 적용된 수동 주문. 화면에서 연습 주문 기능·삭제 버튼·문구를 제거했으며 기존 DB 기록과 호환 API는 남아 있습니다.
- 공통 헤더: 입력형 종목 검색과 자동완성, `/` 키 검색 포커스, 연결 상태·화면 잠금을 제공합니다. FOLIO 로고는 자산 현황으로 이동하며 주문 인증은 사이드바에 둡니다. 전체 자산 가리기는 내 자산 탭에서만 표시합니다.
- 화면 구역 탭은 페이지 스크롤 중 상단에 유지하며 큰 제목·자산 요약은 함께 고정하지 않습니다. 국내 주식은 검색·시장·유형·정렬·차트 기간·표시 개수 입력 줄 자체를 유지하며 좁은 화면에서는 가로로 넘겨 조작합니다. 국내 주식과 모의 주문 기록은 기본 20개, 50·100개 선택과 하단 페이지 이동을 제공하며 페이지 변경 시 목록 시작으로 이동합니다. 자산 현황·국내 주식·모의매매의 표 제목은 페이지·가로 스크롤에 맞춰 유지하며 별도 세로 스크롤 영역은 만들지 않습니다.
- 국내 주식·모의매매에는 현재 등록된 연결의 캘린더로 국내·미국 정규장 상태와 휴장 여부, 다음 개장 또는 종료 시각을 한국시간으로 표시합니다. 미국 조회 날짜는 뉴욕 현지 날짜입니다. 시장 상태와 시세 연결 상태는 별개이며, 확인에 실패하면 열린 것으로 간주하지 않습니다. 헤더는 정규장 상태를 표시하고 PAPER 엔진은 프리·정규·애프터의 연속 거래 구간을 사용하므로 표시 범위가 다릅니다.
- 내 자산 가리기: 전체 또는 카드별 눈 아이콘으로 금액·수익률을 가리고 다시 표시합니다. 전체 가리기는 계좌 표시와 보유 종목도 포함하며, 가림 선택만 브라우저에 저장합니다. 가린 영역은 실제 값 대신 흐릿한 대체 표시를 사용하고 자동 갱신 후에도 유지됩니다.

- 장기 리서치의 저장한 기업에서 기업 메모(최대 2,000자)를 DB에 저장·수정합니다. 메모는 사용자별로 분리되며 기업명·코드·메모 검색과 점수·최근 추가·이름 정렬, 종목별 뉴스 이동을 제공합니다. 분석 팝업과 종목 상세의 저장됨 버튼을 눌러 저장을 해제하며 관심종목과 메모는 유지합니다. 해제한 기업은 리서치 목록에 다시 나타나지 않고, 재저장하면 기존 메모를 복원합니다.

## 인증과 안전

- 로그인 세션은 기본 12시간이며 활동 시 만료 시각이 연장됩니다.
- 헤더의 화면 잠금은 세션을 종료하지 않고 조작만 막습니다. PIN으로 해제해도 PAPER 실행 상태는 유지됩니다.
- LIVE 주문은 별도 주문 PIN, 입력 검증, 중복 방지, 위험 한도와 서버 안전 잠금을 거칩니다.
- 모의매매와 실제 주문 경로는 분리되어 있으며, 실제 자동 주문은 아직 운영 기능이 아닙니다. 내부 `DRY_RUN` 값은 모의매매 전략 구분으로 남지만 사용자 화면의 연습 주문 기능과는 다릅니다.

## 장기 관찰 분석

- 최근 사업보고서와 가격·재무 지표를 저장해 재사용하고 정해진 주기에만 갱신합니다.
- 100점 점수와 S/A/B/C/D 등급을 함께 표시합니다.
- 자동 추천은 저장된 분석 가운데 기준 점수 이상인 자동 선별 후보를 사용합니다.
- 자동 추천은 70점, 핵심 평가 항목 수, 실적 추세, 영업흑자, 부채비율과 최대 낙폭을 함께 확인하며 별도 기준이 필요한 금융·지주 업종은 현재 제외합니다.
- 관심종목이나 사용자가 직접 추가한 내 관찰 후보는 자동 추천에서 제외합니다.
- 개발 중에는 장기투자 화면에서 최대 20개 후보를 직접 다시 분석하며, 추천 화면은 기준을 통과한 상위 최대 5개를 표시합니다.
- 현재 로컬 개발 환경의 자동 분석 시각은 매일 09:10(KST)입니다. 코드와 `.env.example` 기본값은 04:30이며, 정식 상시 운영 전 로컬 설정도 04:30으로 맞출 예정입니다.
- 분석 실행 중에는 주요 화면 상단에 점검 안내 배너가 표시됩니다.

## PAPER와 데이터

- PAPER 신호는 토스 현재가와 완료된 1분봉을 사용합니다. 시세가 늦은 종목만 대기하고 정상 종목은 판단을 계속합니다.
- 계좌별 CURRENT/AUTO/ALL 관리 범위를 선택합니다. 기본값은 자동매수분만 관리하는 AUTO이며 상세 동작은 [PAPER_STRATEGY.md](PAPER_STRATEGY.md)를 참고합니다.
- 모의계좌·실험계좌 화면 전환은 실행 중인 전략을 정지하지 않습니다. 다른 계좌에서 실행 중인 전략을 배너로 표시하며, 일시정지·긴급 중지는 보고 있는 계좌에 적용됩니다. 서버 종료는 두 계좌의 워커를 모두 정지합니다.
- 두 모의계좌의 잔액·포지션·매입단가·비용·주문 상태는 PostgreSQL에 저장하고 재시작 시 복구합니다. 마지막 선택 전략도 계좌별로 복원하며 자동매매는 정지 상태입니다. 복원된 전략을 확인한 뒤 전략 시작을 누릅니다.
- 주문 감사 기록은 기존 관리자 계좌의 `.paper-history/orders.jsonl` 또는 사용자·계좌별 파일에 남습니다. 정확한 경로와 복원 범위는 [DATABASE.md](DATABASE.md)를 참고합니다.
- 전략, 위험 설정, 인증, 관심종목, LIVE 기록, 장기 분석·추천·관찰 목록은 PostgreSQL에 저장됩니다.

## 알려진 제한

- 개인용 운용·단일 앱 프로세스를 전제로 합니다. 사용자별 연결·모의계좌·워커는 분리했지만 회원가입·공개 서비스·여러 실제 계좌 전환은 제공하지 않습니다. 시세 시뮬레이터와 ML 정기 수집·장기 추천 작업 등 서버 공통 작업은 여전히 공유합니다.
- 현재 서버는 로컬 주소로 실행하며 외부 접속·휴대폰 앱·원격 정지·푸시 알림은 구현하지 않았습니다. 외부 연결 전 인증·HTTPS·접근 제어와 연결 끊김 처리 설계가 필요합니다.
- 최초 키 등록·키 파일 유실 시에도 DB와 관리자 계정이 준비되면 로그인할 수 있습니다. 키가 없으면 계정 설정으로 이동하며, 등록·복구 안내를 제공합니다. 실제 키를 바꾸는 운영 검증은 별도로 남아 있습니다.
- 토스 API 요청 한도와 장외 시간에는 일부 시세·차트 데이터가 지연될 수 있습니다.
- PAPER 결과는 전략 검증 자료이며 실제 체결 성과를 보장하지 않습니다.
- 장기 점수는 관찰 우선순위 지표이며 매수 추천이 아닙니다.
- 개발 편의를 위한 PAPER 한도 예외가 환경 변수에 설정될 수 있으므로 릴리스 전에 반드시 제거해야 합니다.

## Windows 간편 실행 (2026-10-04)

루트 `FOLIO.cmd`가 최초 Python 가상환경·기본 패키지를 준비하고 DB 확인·꺼진 로컬 PostgreSQL 서비스 시작·최초 계정 생성·서버 시작·브라우저 열기를 처리합니다. Python·PostgreSQL 설치와 최초 DB 생성은 설치 안내를 따릅니다. 기존 설정·DB·로컬 키를 유지하고 실행 중인 같은 폴더의 서버는 재사용합니다. 서버 종료는 실행 창에서 Ctrl+C이며 공유 DB 서비스는 유지합니다. 서버는 로컬 접속만 제공하고 자동매매는 재시작 후 직접 시작해야 합니다.
