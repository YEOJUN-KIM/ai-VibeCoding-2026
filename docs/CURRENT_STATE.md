# 현재 구현 상태

기준일: 2026-10-02

## 사용자 화면

- 로그인: 관리자 PIN 인증, DB·토스 API 준비 상태 안내
- 국내주식: 종목 탐색, 관심종목, 시장 데이터 사전 로딩
- 종목 상세: 차트, 기업정보, 시장정보, 뉴스, 장기 관찰 분석, LIVE 수동 주문
- 장기투자: 자동 추천 후보와 내 관찰 후보를 분리해 표시
- 뉴스: 유사 주제를 묶어 한 이슈가 화면을 독점하지 않도록 정리
- 전략 설정: 독립된 2열 입력 영역, 최근 선택한 3개 전략, 전체 전략 5열 검색 팝업, 상단 저장·삭제 버튼
- 기본 인기·가성비 프리셋: 월요일(KST) 기준 주간 첫 미리보기에서 후보 데이터를 갱신·DB 저장하고 같은 주에는 유지합니다. 예산별 후보·예상 수량과 기준일을 표시하며, 마음에 드는 구성은 이름을 바꿔 별도 저장하도록 안내합니다. 저장된 전략은 자동 변경하지 않습니다.
- PAPER: 계좌·실행 상태와 성과를 위에 표시하고 결과 탭과 전략 설정 사이드바로 구성합니다. 보유 표에서 담당 전략·관리 상태·전략별 수량과 청산 조건을 확인합니다.
- LIVE: 실제 계좌 자산 조회, 주문 기록과 안전장치가 적용된 수동 주문

## 인증과 안전

- 로그인 세션은 기본 12시간이며 활동 시 만료 시각이 연장됩니다.
- 헤더의 화면 잠금은 세션을 종료하지 않고 조작만 막습니다. PIN으로 해제해도 PAPER 실행 상태는 유지됩니다.
- LIVE 주문은 별도 주문 PIN, 입력 검증, 중복 방지, 위험 한도와 서버 안전 잠금을 거칩니다.
- LIVE 자동매매용 실행 구조와 DRY RUN은 분리되어 있으며, 실제 자동 주문은 아직 운영 기능이 아닙니다.

## 장기 관찰 분석

- 최근 사업보고서와 가격·재무 지표를 저장해 재사용하고 정해진 주기에만 갱신합니다.
- 100점 점수와 S/A/B/C/D 등급을 함께 표시합니다.
- 자동 추천은 저장된 분석 가운데 기준 점수 이상인 자동 선별 후보를 사용합니다.
- 자동 추천은 70점, 핵심 평가 항목 수, 실적 추세, 영업흑자, 부채비율과 최대 낙폭을 함께 확인하며 별도 기준이 필요한 금융·지주 업종은 현재 제외합니다.
- 관심종목이나 사용자가 직접 추가한 내 관찰 후보는 자동 추천에서 제외합니다.
- 개발 중에는 장기투자 화면에서 최대 20개 후보를 직접 다시 분석해 추천 5개를 갱신할 수 있습니다.
- 개발 중 자동 분석 시각은 매일 09:10(KST)이며 정식 상시 운영 전 04:30으로 변경할 예정입니다.
- 분석 실행 중에는 주요 화면 상단에 점검 안내 배너가 표시됩니다.

## PAPER와 데이터

- PAPER 신호는 토스 현재가와 완료된 1분봉을 사용합니다. 시세가 늦은 종목만 대기하고 정상 종목은 판단을 계속합니다.
- 계좌별 CURRENT/AUTO/ALL 관리 범위를 선택합니다. 기본값은 자동매수분만 관리하는 AUTO이며 상세 동작은 [PAPER_STRATEGY.md](PAPER_STRATEGY.md)를 참고합니다.
- 모의계좌·실험계좌 화면 전환은 실행 중인 전략을 정지하지 않습니다. 다른 계좌에서 실행 중인 전략을 배너로 표시하며, 일시정지·긴급 중지는 보고 있는 계좌에 적용됩니다. 서버 종료는 두 계좌의 워커를 모두 정지합니다.
- 두 모의계좌의 잔액·포지션·매입단가·비용·주문 상태는 PostgreSQL에 저장하고 재시작 시 복구합니다. 자동매매는 정지 상태이며 전략을 다시 선택해 실행합니다.
- 주문 감사 기록은 `.paper-history/orders.jsonl`에 남습니다.
- 전략, 위험 설정, 인증, 관심종목, LIVE 기록, 장기 분석·추천·관찰 목록은 PostgreSQL에 저장됩니다.

## 알려진 제한

- 단일 사용자·단일 앱 프로세스를 전제로 합니다.
- 토스 API 요청 한도와 장외 시간에는 일부 시세·차트 데이터가 지연될 수 있습니다.
- PAPER 결과는 전략 검증 자료이며 실제 체결 성과를 보장하지 않습니다.
- 장기 점수는 관찰 우선순위 지표이며 매수 추천이 아닙니다.
- 개발 편의를 위한 PAPER 한도 예외가 환경 변수에 설정될 수 있으므로 릴리스 전에 반드시 제거해야 합니다.
