# 현재 구현 상태

기준일: 2026-10-04. 이 문서는 현재 제공 기능을 설명하며 실행 중인 서버·전략 상태를 보장하지 않습니다.

## 진행 단계

기본 기능은 대부분 구현했습니다. 현재는 데이터 축적·품질 확인·장중 모의 운용 검증 단계입니다. 이동평균 기준선 백테스트의 첫 실행은 확인했지만 여러 거래일 검증, 매매용 모델 학습, 실시간 모델 판단 연결과 실제 자동매매는 남아 있습니다. [다음 작업](ROADMAP.md)과 [학습 진행](machine-learning/CURRENT_PROGRESS.md)을 기준으로 진행합니다.

## 사용자 화면

| 화면 | 주소 | 제공 기능 |
|---|---|---|
| 로그인 | `/login` | 아이디·비밀번호, 계정 저장소 준비 상태. 증권 연결이 없어도 로그인 가능 |
| 자산 현황 | `/live` | 실제 자산·보유·현금, 자산 흐름·구성, 관심종목·종목 탐색·실제 주문 관리 |
| 국내 주식 | `/stocks` | 이름·코드·초성·별명 검색, 필터·정렬·페이지 이동, 실제 시세·최근 흐름 |
| 종목 상세 | `/stocks/{종목코드}` | 캔들·라인·거래량·기간별 차트, 기업·공시·뉴스·분석, 실제 수동 주문 |
| 모의매매 | `/paper` | 보유 종목, 계좌·전략, 현재 전략 판단, 주문 기록, 투자 한도 |
| 장기 리서치 | `/long-term` | 추천 기업·저장한 기업·ETF 탐색, 점수·근거, 기업 메모·저장 해제 |
| 주요 뉴스 | `/news` | 시장·종목 기사, 유사 주제 묶음, 이슈별 기사 이동 |
| 설정 | `/settings` | 계정·연결 → 자동매매 전략 → 투자 한도. 비밀번호·PIN·API 연결 변경 팝업 |

공통 화면은 차콜 배경·바이올렛 강조를 사용하고 손익에는 빨강·파랑을 유지합니다. 상단 입력형 검색은 자동완성과 `/` 키 포커스를 제공하며 FOLIO 로고는 자산 현황으로 이동합니다. 화면 잠금은 헤더, 주문 인증은 사이드바에 있습니다. 구역 탭·마켓 필터·표 제목은 스크롤 중 유지합니다. 검색 규칙·기업 아이콘·시안·자산 차트의 범위는 [화면·검색 설계](technical/UI_DESIGN.md)를 참고합니다.

## 계정·연결과 실제 주문

- 개인용 Windows 로컬 웹앱입니다. 공개 가입 서비스·여러 실제 계좌 전환은 지원하지 않습니다. 연결·모의계좌·실행 상태·투자 한도·선택 계좌는 사용자별로 분리합니다. 최초 관리자 연결을 다른 사용자에게 상속하지 않습니다.
- 새 비밀번호는 8~20자, PIN은 숫자 6자리입니다. 활동 기반 세션은 기본 12시간이며 비밀번호 변경은 세션을, PIN·연결 변경은 주문 인증을 무효화합니다.
- 설정에서 새로 등록한 키는 `.local-secrets/`에 Windows DPAPI로 암호화해 저장합니다. DB에는 연결 정보만 저장합니다. 기존 관리자 환경 설정 키는 `.env`를 사용합니다. 새 PC·키 유실 시 재등록하며 미연결 사용자는 계정 설정에서 복구합니다.
- 동일한 증권 계좌의 중복 연결·다른 실제 계좌로 교체를 차단합니다. 전략 실행 또는 미완료 실제 주문이 있으면 연결 변경을 막습니다.
- 실제 주문은 수동 주문이며 PIN·입력 검증·서버 안전 잠금·위험 한도·중복 방지·브로커 상태 대조를 적용합니다. 실제 주문 자동 실행은 아직 제공하지 않습니다.
- 사용자 화면에 별도 연습 주문 기능은 없습니다. 과거 호환 데이터·내부 API와 모의 전략의 `DRY_RUN` 저장값은 남아 있으며 실제 주문 관리 화면은 실제 주문만 조회합니다.

## 모의매매

- 실제 자산을 복사하는 기존 모의계좌와 분리된 실험계좌를 제공합니다. 계좌 카드로 전환하고 전략 선택 → 전략 시작 순서로 실행합니다. 선택만으로 주문하지 않습니다.
- 완료된 1분봉 신호, 비용 포함 매수 규모, 익절·손절·최대 보유일·추세 청산, 투자 한도·재매수 대기를 적용합니다. 일부 종목 시세가 지연되면 해당 종목만 대기합니다.
- 자동매수분별 전략·수량·취득 시각·청산 조건을 보관하고 CURRENT/AUTO/ALL 관리 범위를 선택합니다. 기본은 자동매수분만 관리하는 AUTO입니다.
- 계좌 전환은 이전 계좌 워커를 정지하지 않습니다. 일시정지·긴급 중지는 현재 계좌의 자동 판단·청산을 모두 멈추며 보유분을 자동 매도하지 않습니다. 화면 잠금도 전략을 정지하지 않습니다.
- 국내 통합시장 캘린더의 연속 거래 구간과 전략 운영 시간의 교집합에서 판단합니다. 휴장·시간 밖·단일가·캘린더 확인 실패에는 매수와 청산이 모두 대기합니다. 헤더는 국내·미국 **정규장** 상태만 표시하며 범위가 다릅니다.
- 계좌 자산·주문·관리 범위·마지막 선택 계좌와 전략은 DB에서 복원합니다. 재시작 후 실행은 정지 상태이며 성과 기준선·화면 최신 판단은 초기화됩니다. 주문 기록은 날짜·종목·방향·상태로 조회하고 비용·실현손익·상세 이유를 확인합니다.
- 사용자에게 개발·점검용 과거 판단 조회 화면을 제공하지 않습니다. 학습용 판단 기록은 DB에 보존합니다.

현재 신호·체결·손익의 정확한 기준은 [모의 전략 설명](specs/PAPER_STRATEGY.md), 복원·백업은 [저장 정책](technical/DATABASE.md)에 둡니다.

## 리서치·프리셋·학습 자료

- 리서치는 재무·가격 자료로 100점·등급·근거를 표시합니다. 추천은 기준을 통과한 후보 중 최대 5개이며 저장한 기업과 구분합니다. 메모는 사용자별로 저장하고 저장 해제 후에도 유지합니다. 예약 시각은 로컬 설정에 따라 달라지며 현재 개발 설정은 09:10(KST), 코드·환경 예시 기본값은 04:30입니다.
- 주간 인기·가성비 프리셋은 월요일 기준 첫 미리보기에서 후보를 갱신해 DB에 보관합니다. 조건을 통과한 종목을 거래대금 순으로 최대 10개 선정하며 저장한 전략을 자동 변경하지 않습니다. 기본 운영 시간은 08:00~20:00(KST)입니다. 거래대금 순위는 수익성 평가가 아닙니다.
- 학습용 종목·국내 지수 1분봉, 환율·미국 지표, 모의 전략 판단과 일일 품질 보고서를 저장합니다. 원본 수집 일정은 전략 엔진 캘린더 제한과 별개입니다. 뉴스·공시 화면 조회가 학습용 시점별 원본 저장을 뜻하지 않습니다.
- 환경 확인용 예제 모델은 있지만 매매용 모델은 아직 학습하지 않았습니다. 현재 자료 범위·건수·검증 날짜는 [학습 진행 상태](machine-learning/CURRENT_PROGRESS.md)를 참고합니다.

## 실행과 알려진 제한

`FOLIO.cmd`는 가상환경·기본 패키지 준비, DB 확인·로컬 서비스 시작, 최초 계정 생성, 서버·브라우저 실행을 이어서 처리합니다. Python·PostgreSQL 설치와 최초 DB 생성은 필요합니다. 같은 폴더의 서버는 재사용하고 Ctrl+C로 종료하며 공유 DB 서비스는 유지합니다. [설치·실행 안내](guides/INSTALL_WINDOWS.md)를 따릅니다.

- 서버·PC가 꺼지면 수집·전략 실행도 멈춥니다. 휴대폰 원격 확인·정지, 설치 프로그램, 설정 동기화·모델 배포는 계획만 있으며 구현하지 않았습니다.
- 실제 자산 차트는 화면 조회 시 축적된 날짜별 기록만 사용합니다. 입출금이 반영되는 총자산 흐름이며 투자 수익률 차트가 아닙니다.
- 개발용 모의 한도 예외·장기 분석 예약 시각을 릴리스 전에 정리해야 합니다. 비용·체결 가정의 제한은 모의 전략 설명을 따릅니다.
- 현재 PC의 연결 재등록 후 재시작·자산 조회와 임시 DB 백업 복원은 확인했습니다. 다른 PC의 설치·권한·키 재등록·전체 이전과 장기간 운용은 별도 검증이 필요합니다.
