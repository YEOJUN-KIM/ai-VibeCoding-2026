### 화면 배치와 모의매매 사용 흐름 정리

- 주요 페이지의 구역 메뉴를 화면 왼쪽에 붙는 공통 사이드바로 정리했다. 구역 메뉴가 없는 마켓도 같은 공간을 유지하고, 작은 화면에서는 메뉴와 콘텐츠를 화면 너비에 맞춰 배치한다.
- 설정의 기본 프리셋과 최근 선택한 전략을 나란히 배치했다. 프리셋 미리보기는 팝업으로 열고 상단 닫기·Esc·배경 클릭으로 닫으며, 중복된 하단 닫기 버튼을 제거했다.
- 미리보기를 열기 전에도 주간 데이터 생성 시각·다음 갱신 기준일·현재 데이터 상태를 표시한다. 다음 주 첫 미리보기에서 갱신하는 방식이며 정해진 시각의 예약 갱신이 아니라는 점과 저장된 전략은 변경되지 않는다는 점을 안내한다.
- 마켓 브리프의 보도 흐름 요약에 이슈별 바로가기를 추가해 해당 기사 묶음으로 이동할 수 있게 했다.
- PAPER 메뉴를 보유 종목 → 계좌·전략 → 전략 판단 → 주문 기록 → 투자 한도 순서로 정리했다. 우측의 계좌·전략 제어를 별도 탭으로 옮겨 결과 화면의 너비를 확보했다.
- 계좌·전략 탭을 계좌 확인 → 전략 선택·적용 → 실행의 세 단계로 재구성했다. 계좌 비교 카드는 작은 요약으로 줄이고 상세 성과는 펼쳐서 확인한다. 초기화·자산 복사는 접힌 관리 메뉴로 옮겼다.
- 현재 상태에 따라 다음 할 일을 안내하고 전략 미선택·변경 적용 전·실행 중·긴급 중지 상태를 구분한다. 실행 중 선택이 잠기는 이유와 일시정지 위치를 설명하며, 적용된 전략과 보유분 관리 범위는 항상 표시한다. 새 전략을 고르고 적용하지 않은 상태에서는 이전 전략을 시작하지 않도록 막는다.
- 전략 판단의 큰 시세 기준 영역을 제목 옆 최근 조회 시각으로 줄이고 시세 대기·오류 안내는 유지했다. 보유분 감시, 진입 대기, 재매수 대기와 현재 주문 제한을 구분하고 판단 열 제목을 중앙 정렬했다.
- 주문 기록에 한국시간 기준 시작일·종료일 필터를 추가하고 기간 입력을 한 영역으로 묶었다. 종목명·코드 검색, 별도 전략 열, 긴 이름 말줄임과 전체 이름 확인, 건수 요약, 표 정렬을 정리하고 전체 거래 기록 다운로드를 하단으로 이동했다. 기록에서 전략 이름과 판단 이유를 분리하며, 확인할 수 없는 전략 이름은 현재 전략으로 단정하지 않는다.
- 안전 기준 탭을 투자 한도로 바꾸고 현재 사용량·제한 사유·주문에 적용되는 기준을 카드로 나누었다. 설정 이동 링크와 한도의 적용 목적을 함께 안내한다.
- 재시작 후 두 모의계좌의 잔액·보유분·주문 기록 유지와 자동매매 정지 상태를 확인했다. 프리셋 상태, 계좌별 실행 요약, 주문 필터·페이지 이동, 전략 선택·상태 안내와 투자 한도의 관련 회귀 검증을 통과했다. 데스크톱·좁은 화면과 상세 펼치기·결과 탭 이동을 확인했다.
- 첫 사용자를 위한 영역 강조·단계별 설명 투어와 페이지별 가이드북은 전체 기능·화면 안정화 이후의 장기 보류 작업으로 [BACKLOG.md](BACKLOG.md)에 기록했다.
