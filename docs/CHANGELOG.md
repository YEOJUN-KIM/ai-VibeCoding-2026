# 작업 기록

## 2026-09-25

### LIVE 자산 대시보드

- 로그인 성공 후 첫 화면을 LIVE 실제계좌로 변경했다.
- PAPER/LIVE 전환 버튼을 여러 페이지로 확장할 수 있는 공통 내비게이션으로 바꿨다.
- 국내 장 운영 캘린더를 적용해 휴장일에는 최근 거래일 평가손익과 기준일을 표시한다.
- 원화·달러 주문 가능 금액과 추정 총자산을 표시하고, 자산 카드 이름은 `원화`, `달러`로 정리했다.
- LIVE 화면의 중복 국내 종목 검색을 제거하고 `국내주식 마켓 스캐너`를 배치했다.
- 스캐너와 관심종목의 종목명을 누르면 해당 종목 상세 페이지로 이동하도록 연결했다.

### 국내주식 마켓

- `/stocks`에 코스피·코스닥 전체 종목 목록을 만들고 검색, 시장·유형 필터, 정렬, 페이지 이동과 관심종목 기능을 연결했다.
- 목록에는 현재가, 등락률, 시가총액, 실제 거래대금과 최근 흐름을 표시한다.
- 최근 흐름 기간을 1일·7일·1개월·3개월·1년으로 구성하고 기본값을 1일로 설정했다.
- 작은 차트에 곡선 보간, 상승·하락 색상, 그라데이션과 글로우 효과를 적용했다.
- 1일 차트는 과도한 점 수를 줄이고 7일 차트는 보간 점을 늘려 기간별 밀도를 조정했다.
- 차트 데이터를 묶음으로 불러오고 캐시와 서버 시작 시 종목 목록 예열을 적용해 첫 화면과 검색 응답을 개선했다.

### 종목 대시보드

- `/stocks/{symbol}` 상세 화면과 1일·7일·1개월·3개월·1년 기간 선택을 구현했다.
- 캔들·라인 보기, 거래량, 시·고·저·종, 시가총액, 거래대금, 거래량과 상장주식수를 제공한다.
- 기본 기간은 1일이며, 1일·7일·1개월은 분봉 데이터를 여러 페이지로 수집해 화면 폭에 맞게 집계한다.
- 3개월·1년은 일봉 데이터를 사용하고 기간별 캔들 수를 늘려 흐름을 더 촘촘하게 보이도록 조정했다.
- 마우스를 올리면 십자선과 함께 날짜·시간, OHLC, 종가 기준 등락률, 거래량을 확인할 수 있다.
- MA5·MA20 이동평균선, 현재가 기준선·가격표와 장중 가격 공백 표시를 추가했다.
- 휴장·비거래 구간을 임의 가격으로 채우지 않고 공백으로 표현해 차트 왜곡을 피했다.

### 화면 문구와 구조

- 주요 화면 이름을 `투자 데스크 로그인`, `LIVE 자산 대시보드`, `PAPER 트레이딩 랩`, `국내주식 마켓`, `종목 대시보드`로 정리했다.
- `관심종목 워치리스트`, `종목 디렉터리`, `가격·거래량 차트`, `마켓 스냅샷` 등 제목과 설명을 기능 중심으로 다듬었다.
- 국내주식 목록 표에서는 종목 유형 열을 빼고 시가총액을 표시하되, 종목 유형 필터는 유지했다.

### 확인

- Python 단위 테스트와 프런트엔드 JavaScript 문법 검사를 통과했다.
- 토스 캔들 API의 페이지 커서 처리와 상세 분봉 수집을 단위 테스트로 확인했다.
