# 보류 기능

지금 구현하지 않을 아이디어를 잊지 않기 위한 목록입니다. 착수할 때 범위와 완료 조건을 정해 [ROADMAP.md](ROADMAP.md)로 옮깁니다.

## PAPER 데이터와 전략 연구

- 프리셋 갱신 버튼: 오래된 기본 프리셋을 현재 시장 메타와 최신 전략 규칙에 맞춰 다시 생성하되, 사용자가 직접 수정한 전략은 확인 없이 덮어쓰지 않기
- PAPER 계좌, 포지션, 판단, 체결과 실행 상태 전체 영속화
- 장기간 축적한 시장·전략 결과를 이용한 성과 분석
- 전략 버전별 비교, 구간별 백테스트와 재현 가능한 리플레이
- 충분한 데이터가 모인 뒤 전략 개선 제안 또는 제한된 자동 튜닝

데이터가 적은 현재는 자동 학습을 구현하지 않습니다. 먼저 데이터 정의, 품질 검증, 과최적화 방지와 변경 승인 절차가 필요합니다.
학습과 구현 순서는 [머신러닝 학습 과정](machine-learning/README.md)에 별도로 정리합니다.

## LIVE 자동매매

- PAPER에서 승인한 전략의 LIVE 실행
- 장중 재시작 복구, 미체결 대조, 부분 체결과 취소·정정 처리
- 종목·전략별 손실 차단과 전체 비상 정지
- 실행 전 시뮬레이션 결과와 운영 체크리스트 강제

현재 LIVE는 계좌 조회와 사용자가 확인하는 수동 주문까지만 운영 범위입니다.

## 투자 분석 확장

- 장기 후보 여러 종목 비교표와 점수 변화 이력
- 업종별 평가 기준과 현금흐름·밸류에이션 고도화
- 해외주식과 환율·세금 처리
- AI 뉴스 요약·영향도 분석 재검토

## 사용자와 운영

### 첫 사용자를 위한 화면 안내·가이드북 (장기 보류)

주요 기능과 화면 구성이 완성되고 안정된 뒤 진행합니다. 당장의 구현 작업이 아니라, 처음 접하는 사람이 각 항목의 의미와 사용 순서를 이해하도록 돕는 후속 작업입니다.

- 첫 실행 또는 페이지 첫 방문 때 선택적으로 시작하는 단계별 안내 투어
- 설명하는 버튼·카드·영역을 강조하고, 짧은 설명을 읽은 뒤 `다음`으로 이동하는 흐름
- `이전`, `건너뛰기`, `닫기` 제공 및 안내 완료 여부 저장. 도움말에서 다시 실행 가능
- 페이지별 기능과 용어를 간단히 정리한 가이드북·도움말 제공
- 모의매매는 계좌 종류, 전략 선택·적용·실행 순서, 보유분 관리 범위, 판단·주문 기록, 일시정지·긴급 중지의 의미를 안내
- 안내 중 실제 설정 변경이나 주문·전략 실행을 자동으로 수행하지 않기
- 작은 화면과 키보드 사용에서도 강조 영역·설명·이동 버튼을 확인할 수 있도록 구성

착수할 때 전체 페이지의 안내 범위와 완료 조건을 정하고 로드맵으로 옮깁니다.

### 기타 후보

- 다중 사용자, 권한과 사용자별 포트폴리오 분리
- 알림 채널과 중요 이벤트 통지
- 상시 운영 환경, 모니터링과 장애 알림
- PostgreSQL 정기 백업, 보관 주기, 암호화와 복구 훈련 자동화
