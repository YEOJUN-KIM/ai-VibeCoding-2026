## 데이터 제약과 선택

원본은 기간별 기준 자산·증분 배열과 축의 날짜/시각 문자열을 별도로 갖고 있으며, **중간 증분의 개별 시각은 없다**. 원본 중간 축도 표본과 연결되어 있지 않았다. 이를 역사적 표본으로 취급하거나 임의의 날짜를 배정하지 않았다. 중간 증분은 원본 reference에 전부 보존하고, 화면에는 출처에서 날짜·금액을 함께 확인할 수 있는 시작/끝 2개만 표시한다. 연결선은 중간 측정값을 뜻하지 않는다. 촘촘한 곡선을 복원하려면 원래 표본별 timestamp가 추가로 필요하다.

일자만 있는 시작 표본은 **시각 미제공**으로 표시한다. 내부 위치 계산용 00:00 KST는 측정 시각으로 노출하지 않는다. 원본의 2025.11/2026.05 축과 날짜 없는 1년 중간 +100,000원 표본을 새 역사로 만들지 않았다. 1년 버튼은 1년 미만 운용 안내를 유지하고 확인 가능한 1개월 구간을 표시한다. 10.11은 원본의 최초 확인 가능한 기준점이며 실제 엔진의 운용 개시일을 검증한 것이 아니다.

Y 범위는 `max(관측범위, 시작자산의 2%) × 1.2`. 0.3424% 당일 변화가 200px plot 높이의 약 28.5px로 표현되어 작은 변화를 과장하지 않는다. 0 기준 고정축은 아니며 숫자축은 요청대로 숨겼다. SVG·브라우저 기본 기능으로 의존성을 추가하지 않았지만 데이터 제약으로 상세 추이는 보여주지 못한다.
