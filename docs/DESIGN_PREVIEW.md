- 계좌·전략 상단의 카드 전체를 클릭하거나 키보드로 선택하면 기존 계좌 전환 API로 표시 계좌를 전환합니다. 현재 계좌 재선택과 전환 중 중복 요청은 무시합니다. 기존의 별도 계좌 전환 버튼은 숨겼습니다.
- 상세는 해당 카드만 펼치며 계좌 선택에 영향을 주지 않습니다. 새 조회에서도 계좌별 펼침 상태를 유지합니다.
- 초기화·실제 자산 복사는 1번 계좌 확인 영역 아래의 접을 수 있는 계좌 관리 메뉴에 배치했습니다. 기존 확인 절차와 동작은 유지합니다.
- 검증: 실제 카드 렌더·전환 함수를 사용한 예시 데이터 화면에서 카드 전환 및 상세 클릭 후 요청 횟수 유지 확인. 기존 모의매매 상태 테스트 통과. 실제 계좌 전환 API를 실행해 계좌 상태를 변경하지 않았습니다.

## 상단 검색 직접 입력

- 상단 검색을 팝업 버튼에서 직접 입력창으로 바꿨습니다. 결과는 입력창 아래에서 표시하며 `/` 키는 입력창에 포커스만 옮깁니다. 다른 입력창에 입력 중이면 단축키를 가로채지 않습니다.
- 방향키 결과 탐색, Enter 선택, Esc 및 외부 클릭 닫기를 제공합니다. 기존 검색 API·100ms 대기·요청 취소·응답 순서 검사는 유지하며 한국어 조합 중 요청을 멈춥니다.
- 실제 공통 검색 스크립트와 예시 응답으로 직접 입력, 단축키 포커스, 방향키, Esc, 외부 포커스 이동을 브라우저에서 확인했습니다. 임시 검증 파일은 제거했습니다.

- 비밀번호와 PIN 변경에는 현재 로그인 비밀번호 및 CSRF 검증이 필요합니다. 비밀번호 변경은 해당 사용자의 모든 세션을 만료시키며, PIN 변경은 모든 세션의 주문 인증을 해제합니다.
- 변경 실패 횟수는 기존 로그인 잠금 정책을 적용하고, 실패 응답 전에 DB에 저장합니다.
- 연결 계좌는 번호를 가려 표시합니다. 이후 사용자별 증권 연결을 분리하고 API 연결 등록·변경 팝업을 추가했습니다. 개인용 앱 기준으로 새 키는 DB 대신 Windows 암호화 로컬 파일에 저장합니다. 같은 증권 계좌의 API 키 갱신만 허용하며, 실행 중인 전략·미완료 실제 주문이 있으면 변경을 차단합니다.
- 인증 테스트 13개, 계정 설정 응답 테스트 5개 통과. 브라우저 배치와 연결 확인 버튼은 예시 응답을 사용해 확인했습니다. 실제 계정의 비밀번호/PIN은 변경하지 않았습니다.
- 화면 예시: artifacts/design-preview/account-settings.jpg

- 계정 보안 입력을 비밀번호/PIN별 팝업으로 변경했습니다. 기본 화면에는 정보와 변경 버튼을 표시합니다. 팝업은 현재 비밀번호에 초점을 맞추며 취소·닫기·Esc·바깥 클릭으로 닫고 입력값을 지웁니다. 저장 중에는 닫기와 중복 제출을 막습니다.
- 브라우저에서 두 팝업 열기, 취소, Esc, 초점 복귀, 기본 화면의 입력 숨김을 예시 데이터로 확인했습니다. 화면 예시: artifacts/design-preview/account-password-modal.jpg
