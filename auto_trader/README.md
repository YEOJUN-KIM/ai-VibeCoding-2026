# 국내주식 모의 자동매매

토스증권 API를 연결하기 전에 가상 시세와 가상 자금으로 주문 흐름을 연습하는 FastAPI 프로그램이다.

## 감시 종목

서버 시작 시 토스증권의 국내 일일 거래대금 상위 10개를 감시 종목으로 사용한다. API 연결에 실패하면 코드에 포함된 국내 대표 종목 10개를 사용한다. 실제 가격은 시작값으로만 사용하고 이후 PAPER 가격 변동은 가상 시뮬레이션이다.

## 실행

먼저 설정 예시를 실제 설정 파일로 복사한다.

```powershell
Copy-Item .env.example .env
```

`.env`에서 가상 투자금, 감시 종목과 전략값을 변경할 수 있다. 토스증권 API 값은 비워 두고, PostgreSQL 연결값은 반드시 설정한다. 현재 PC의 DB 설정과 실행법은 [데이터베이스 안내](../docs/DATABASE.md)를 참고한다. 이미 `.env`가 있다면 예시 파일로 덮어쓰지 않는다.

최초 한 번, 웹과 분리된 터미널 명령으로 관리자 계정을 생성한다.

```powershell
python -m auto_trader.create_admin
```

비밀번호는 12자 이상이어야 하며 PostgreSQL에는 원문이 아닌 scrypt 해시만 저장된다. 관리자 계정은 하나만 만들 수 있다.

LIVE 활성화용 6자리 PIN도 웹과 분리된 터미널에서 설정하거나 변경한다.

```powershell
python -m auto_trader.set_live_pin
```

PIN 역시 원문이 아닌 scrypt 해시로 저장된다. 5회 실패하면 기본 15분 동안 잠기며, 인증 성공은 현재 로그인 세션에서 5분간만 유효하다. PIN은 로그인 비밀번호를 대신하지 않으며 실제 LIVE 주문 연결 전 재확인 수단이다.

```powershell
python -m auto_trader
```

실행 후 아래 주소를 사용할 수 있다.

- PAPER 모의매매: `http://127.0.0.1:8000/paper`
- LIVE 실제계좌: `http://127.0.0.1:8000/live`
- API 문서: `http://127.0.0.1:8000/docs`

두 화면 모두 관리자 로그인이 필요하다. 세션은 기본 30분 후 만료되며 로그인 5회 실패 시 기본 15분 동안 잠긴다.

서버 재시작 시 기존 로그인 세션은 만료된다. 로그아웃하면 자동매매도 중지된다.
현재 세션은 로그인 시각부터 30분 고정 만료이며 브라우저를 닫거나 세션이 만료되는 것만으로 모의매매 워커가 중지되지는 않는다. 종료할 때는 중지 또는 로그아웃 버튼을 사용한다.
현재 로그인은 로컬 HTTP 전용이다. 실거래 사전 점검, 추가 인증과 LIVE 활성화는 아직 구현하지 않았다.
Swagger의 변경 요청에는 `/auth/me` 응답의 `csrf_token`을 `X-CSRF-Token` 헤더로 보내야 하므로 일반 조작은 대시보드를 이용한다.

## 현재 범위

- 가상 시세 조회
- 가상 계좌 조회
- 시장가 방식의 즉시 모의 체결
- 주문 내역 조회
- 2초 간격 이동평균 자동매매
- 자동매매 시작·중지·긴급 정지
- 토스증권 OAuth 토큰 발급과 읽기 전용 계좌 목록 연결 점검

## 자동매매 연습

Swagger UI에서 다음 순서로 실행한다.

1. `POST /strategy/start`로 자동매매를 시작한다.
2. 약 40초 후 `GET /strategy/status`에서 이동평균과 신호를 확인한다.
3. `GET /orders`와 `GET /account`에서 가상 체결 결과를 확인한다.
4. `POST /strategy/stop`으로 정상 중지한다.
5. 즉시 멈춰야 할 때는 `POST /strategy/emergency-stop`을 사용한다.

연습용 기본 설정은 시세 갱신 2초, 단기 5개 가격, 장기 20개 가격, 주문 수량 1주다. PAPER 화면에서 자동매매를 중지한 뒤 값을 변경할 수 있다.

PAPER 현금·보유종목·주문·전략 기록은 메모리에만 존재한다. 서버 재시작 시 초기 가상자금으로 돌아가며 로그인·PIN·위험 한도 설정은 PostgreSQL에 유지된다.
