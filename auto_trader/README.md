# 국내주식 PAPER·LIVE 투자 관리 화면

FastAPI 웹 화면에서 모의 자동매매를 연습하고 토스증권 실계좌 자산을 읽기 전용으로 확인하는 개인용 프로젝트다. 전체 Windows 설치 과정은 [설치 가이드](../docs/INSTALL_WINDOWS.md)를 따른다.

## 실행

프로젝트 루트에서 가상환경을 활성화한 뒤 실행한다.

```powershell
.\.venv\Scripts\Activate.ps1
python -m auto_trader
```

- 로그인: `http://127.0.0.1:8000/login`
- PAPER 모의매매: `http://127.0.0.1:8000/paper`
- LIVE 실제계좌 조회: `http://127.0.0.1:8000/live`
- 국내주식 전체 목록: `http://127.0.0.1:8000/stocks`
- 종목 상세: `http://127.0.0.1:8000/stocks/{종목코드}`
- 장기투자 분석: `http://127.0.0.1:8000/long-term`
- 뉴스·리서치: `http://127.0.0.1:8000/news`
- API 문서: `http://127.0.0.1:8000/docs`

`.env`가 없다면 `.env.example`을 복사하고 PostgreSQL과 토스 API 값을 입력한다. 기존 `.env`는 예시 파일로 덮어쓰지 않는다.

## 최초 설정

관리자 계정과 LIVE 숫자 6자리 PIN은 웹이 아닌 터미널에서 설정한다.

```powershell
python -m auto_trader.create_admin
python -m auto_trader.set_live_pin
```

관리자 비밀번호와 PIN 원문은 저장하지 않는다. 로그인 5회 실패 시 기본 15분 동안 잠기며 세션은 기본 12시간 동안 활동할 때마다 연장된다. 서버 재시작 뒤에도 유효한 세션은 유지되며, 자리를 비울 때는 헤더의 화면 잠금을 사용한다.

## 현재 구현 범위

### PAPER

- 실제 시세·완료된 1분봉과 모의 계좌
- 수동 모의 주문과 즉시 체결
- 이동평균 교차 후 2봉·추세·거래비용 조건을 확인하는 자동매매
- 시작·중지·긴급 정지
- 보수적·기본·직접 설정 위험 한도
- 주문, 보유종목, 수수료·세금과 손익 표시

PAPER 거래 상태는 메모리에 있으므로 서버 재시작 시 초기화된다. 관리자, PIN, 관심종목과 위험 설정은 PostgreSQL에 유지된다.

거래 이유·비용·청산손익은 `.paper-history/orders.jsonl`에 보존된다. 현재 최소 현금 비율은 0%, 하루 주문 횟수는 0(무제한)이다. [PAPER 전략 설명](../docs/PAPER_STRATEGY.md)에 손익 계산과 모의 체결 가정을 정리했다.

### LIVE 읽기 전용

- 토스 OAuth 인증과 실제 계좌 조회
- 총자산, 보유주식 평가금액, 원화·달러 주문 가능 금액
- 휴장일을 구분하는 오늘 또는 최근 거래일 평가손익
- 국내주식 마켓 스캐너와 종목 상세 페이지 연결
- PostgreSQL 기반 관심종목 추가·삭제

### 국내주식 탐색

- 코스피·코스닥 전체 종목 검색, 시장·유형 필터와 정렬
- 현재가, 등락률, 시가총액, 거래대금과 기간별 최근 흐름
- 1일·7일·1개월·3개월·1년 캔들·라인·거래량 상세 차트
- 상세 차트 십자선 툴팁, 이동평균선, 현재가 기준선과 마켓 스냅샷

### 뉴스·리서치

- 첫 화면에서 최근 24시간 국내 증시 기사 조회
- 시장·산업·종목 키워드 검색
- 유사한 기사 제목을 대표 기사와 관련 기사로 그룹화
- 기사 수·매체 수·최근 게시 시각 표시와 관련 기사 펼치기
- 기사 수·매체 수·최신성을 기준으로 상위 5개 핵심 이슈 표시
- 종목 상세 화면에서 해당 종목의 최근 기사 확인
- 기사 본문은 저장하지 않고 각 언론사 원문으로 연결

### 장기투자 분석

- 국내 보통주 검색과 OpenDART 최근 3개년 연간 실적 연결
- 성장성·수익성·재무안정성·가치지표·배당의 5개 관찰 점수
- 시가총액과 순이익·자본을 이용한 참고 PER·PBR, 1년 수익률과 최대 낙폭
- 긍정 근거와 위험 신호를 분리하고 데이터가 없는 항목은 점수에서 제외

AI 뉴스 브리핑은 서버 구현만 보존되어 있으며 기본값은 비활성화다. 비용과 기사 본문 이용 권한을 결정한 뒤 선택 기능으로 연결한다.

실제 주문은 잠겨 있다. 화면의 종목 후보는 당일 거래대금과 예산 조건에 따른 탐색 자료이며 투자 추천이나 수익 보장이 아니다. 산업·테마 정보는 토스 공식 Open API에 제공되지 않아 아직 표시하지 않는다.
