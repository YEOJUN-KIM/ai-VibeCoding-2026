# Company logo sources

Local SVGs are used to identify listed companies. Originals are unchanged.
The file description pages classify these as PD-textlogo/public domain and note trademark rights.

- 005930 — Samsung Group, https://commons.wikimedia.org/wiki/File:Samsung_logo_wordmark.svg
- 000660 — SK Hynix Inc., https://commons.wikimedia.org/wiki/File:SK_Hynix.svg
- 035420 — Naver corporation, https://commons.wikimedia.org/wiki/File:Naver_Logotype.svg
- 005380 — Hyundai Motor Company, https://commons.wikimedia.org/wiki/File:Hyundai_Motor_Company_logo.svg

Missing or failed logos use a short company name. To add another logo, add its local SVG and stock code to company-icons.js.
