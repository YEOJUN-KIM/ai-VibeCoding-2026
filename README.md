# AI VibeCoding 2026

국내주식 조회, 장기 리서치, 모의 전략 검증과 토스증권 실제 계좌·수동 주문을 한곳에서 다루는 개인용 투자 도구입니다.

## 현재 제공하는 기능

- 아이디·비밀번호 로그인, 12시간 세션 연장, PIN 화면 잠금·주문 인증
- 국내주식 탐색, 상세 차트, 기업정보, 뉴스와 관심종목
- 장기 리서치 점수·등급, 추천 기업과 저장한 기업·기업 메모
- 저장한 전략을 실제 시세로 검증하는 모의 자동매매와 휴장일·거래 시간 제한
- 토스증권 LIVE 자산 조회와 안전장치가 적용된 수동 주문
- 전략 설정, 투자 한도, 현재 판단과 주문 기록

현재 구현 범위와 제한은 [문서 안내](docs/README.md)에서 확인할 수 있습니다.
프로젝트를 만들며 정리한 학습 메모는 [바이브 코딩 학습 노트](docs/VIBE_CODING_NOTES.md)로 분리했습니다.
자동매매 머신러닝 학습 과정은 [머신러닝 문서](docs/machine-learning/README.md)에 단계별로 정리했습니다.

## 현재 진행 단계

기본 기능은 대부분 구현했으며 지금은 데이터 축적·품질 확인·장중 모의 운용과 오류 수정에 집중합니다. 여러 거래일 백테스트와 모델 학습·실시간 모의 판단 연결은 후속 작업입니다. 실제 자동매매는 현재 제공하지 않으며 모의 검증 이후 별도로 구현·검증합니다. 다음 순서는 [로드맵](docs/ROADMAP.md), 세부 학습 상태는 [머신러닝 구현 현황](docs/machine-learning/CURRENT_PROGRESS.md)을 참고합니다.

## 로컬 실행

Windows에서는 프로젝트 폴더의 **FOLIO.cmd**를 더블클릭합니다.

- 처음 실행할 때 가상환경과 기본 패키지를 준비합니다. `.env`가 없으면 예시를 복사하고 DB 설정을 안내합니다.
- 평소에는 DB 확인 → 꺼진 PostgreSQL 서비스 시작 → 서버 시작 → 브라우저 열기를 이어서 처리합니다.
- 이미 같은 폴더의 서버가 켜져 있으면 화면만 열어 중복 실행하지 않습니다.
- 실행 창을 유지하고 종료할 때 **Ctrl+C**를 누릅니다. 브라우저를 닫아도 서버는 계속 실행됩니다. DB 서비스는 유지합니다.
- 재시작 후 모의 전략은 정지 상태입니다. 사이트에서 전략 시작을 눌러야 합니다.

새 PC의 Python·PostgreSQL 설치와 최초 DB 생성은 [Windows 설치 안내](docs/INSTALL_WINDOWS.md)를 따릅니다. 기본 주소는 `http://127.0.0.1:8000`입니다. 머신러닝 학습 패키지는 별도 선택 설치이며 일반 실행에서는 설치하지 않습니다.

개발 중 직접 서버만 실행하려면 `.\.venv\Scripts\python.exe -m auto_trader`를 사용할 수 있습니다.

## 개발 확인

```powershell
python -m unittest discover -s tests -v
```

실계좌 주문은 별도 PIN과 서버 안전 잠금을 모두 통과해야 합니다. 개발 중에는 안전 잠금을 해제하지 않는 것을 기본으로 합니다.
