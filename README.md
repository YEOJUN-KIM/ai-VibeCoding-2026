바이브코딩 리포지토리

## Chapter 1
AI에게 코딩을 시키자, 제대로!

### 개념
코딩을 직접하지는 말 것. AI와 협업해서 새로운 프로그램을 만들자!

#### 기존 개발 방법
요구사항 분석 -> 설계(DB/UI 포함) -> 구현/디버깅 -> 테스트 -> 릴리즈 -> 유지보수

#### 바이브코딩 방식
요구사항정의(PRD) -> AI 코드 생성/디버깅, 테스트 -> 사람 검증 수정 요청, 직접 수정 -> 릴리즈 -> AI 유지보수

#### 핵심 포인트
- AI : 주니어/시니어 개발
- 사람 : PM + 리뷰어

### 바이브코딩 개발환경
- VS Code, VS Code Insider, Android Studio, ...

### Codex
- 설치 후 확장 아이콘 아래, Codex 아이콘 생성 됨

### `/` 슬래시 명령어
채팅 입력창에 `/`를 입력하면 Codex 기능을 빠르게 실행할 수 있다. 표시되는 명령어는 현재 작업 환경과 버전에 따라 달라질 수 있다.

#### `/model`
작업에 사용할 AI 모델을 선택한다.

#### `/plan`
코드를 바로 수정하기 전에 작업 계획부터 세우는 계획 모드를 켜거나 끈다.

#### `/status`
현재 채팅의 모델, 컨텍스트 사용량, 사용 한도 등의 상태를 확인한다.

#### `/compact`
대화 내용을 요약·압축해 컨텍스트 공간을 확보한다.

- PowerShell, CMD 창에서 명령어로 수행하는 Codex
