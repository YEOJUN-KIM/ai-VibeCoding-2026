뉴스·리서치는 공개 RSS의 제목·출처·게시 시각을 사용한다. 유사한 제목은 같은 이슈로 묶고 관련 기사 수와 매체 수를 표시하며, 기사 수·매체 수·최신 시각을 기준으로 상위 5개 핵심 이슈를 보여준다. 기사 본문은 저장하지 않고 원문으로 연결한다.

## Chapter 1
AI에게 코딩을 시키자, 제대로!

### 개념
바이브코딩은 만들고 싶은 기능을 자연어로 설명하면 AI가 코드를 작성하고, 사람이 결과를 확인하며 수정해 나가는 개발 방식이다.

개발자는 모든 코드를 직접 작성하기보다 요구사항을 명확히 전달하고, AI가 만든 코드가 올바르게 동작하는지 검토하는 데 집중한다.

#### 기존 개발 방법
요구사항 분석 -> 설계(DB/UI 포함) -> 구현/디버깅 -> 테스트 -> 릴리즈 -> 유지보수

#### 바이브코딩 방식
요구사항정의(PRD) -> AI 코드 생성/디버깅, 테스트 -> 사람 검증 수정 요청, 직접 수정 -> 릴리즈 -> AI 유지보수

#### 핵심 포인트
- AI : 주니어/시니어 개발
- 사람 : PM + 리뷰어

### `/` 슬래시 명령어
채팅 입력창에 `/`를 입력하면 Codex 기능을 빠르게 실행할 수 있다. 표시되는 명령어는 현재 작업 환경과 버전에 따라 달라질 수 있다.

- `/model` :작업에 사용할 AI 모델을 선택한다.

- `/plan` :코드를 바로 수정하기 전에 작업 계획부터 세우는 계획 모드를 켜거나 끈다.

- `/status` :현재 채팅의 모델, 컨텍스트 사용량, 사용 한도 등의 상태를 확인한다.

- `/compact` :대화 내용을 요약·압축해 컨텍스트 공간을 확보한다.

### 투자 한도 프리셋

로그인 후 대시보드에서 `보수적`, `기본`, `직접 설정`을 선택할 수 있다. 처음에는 1,000만 원 모의자금에 맞춘 **기본 · 연습용 권장** 프리셋이 자동 적용된다.

- 1회 주문 100만 원, 종목별 200만 원, 전체 투자 700만 원
- 주문 후 현금 30% 이상 유지
- 하루 손실 50만 원 또는 하루 체결 100회 도달 시 신규 매수 중지
- 하루 수익 100만 원 도달 시 신규 매수 중지
- 위험을 줄이는 매도 주문은 한도 도달 후에도 허용

일일 손익은 그날 처음 기록된 총자산과 현재 총자산의 차이로 계산한다. 현재는 신규 매수만 막으며 자동 전량매도는 하지 않는다.

`오늘 연습 기록 초기화`는 자동매매를 중지하고 모의 주문·체결·보유종목·손익을 초기 상태로 되돌린다. 관리자 로그인 계정과 선택한 투자 한도는 삭제하지 않는다.

### AI 뉴스 브리핑

AI 뉴스 브리핑의 서버 구현은 보존되어 있으나 비용과 기사 본문 이용 범위를 결정할 때까지 화면 연결과 API 호출을 비활성화했다. 나중에 사용하기로 결정하면 월 비용 한도를 먼저 정한 뒤 `.env`의 `AI_NEWS_ENABLED=true`와 `OPENAI_API_KEY`를 설정하고 UI를 다시 연결한다. 기본 모델은 `gpt-6-luna`이며 API 장애 시 제목 기반 보도 흐름으로 대체하도록 구현되어 있다.
